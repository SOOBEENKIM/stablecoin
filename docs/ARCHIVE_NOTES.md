# 보존 기록과 공개 패키지의 범위

`research/`는 2026-09-11에 `stablecoin_workshop`에서 복사한 연구 기록이다. 917개 파일의 내용과 SHA-256을 유지했다. 기존 폴더의 과거 README가 당시 자신을 ‘최신’이라고 부르는 표현은 고치지 않았다. **현재 최신 단계는 `option1_factorial_20260910`**이며 루트 README가 현재의 색인이다.

`docs/research/`와 `docs/context/`는 GitHub 탐색용 Markdown 사본이다. 보고서 내용·수치를 보존하면서 파일 링크를 상대 경로로 변환하고, 원본으로 돌아가는 링크를 붙였다. 원본의 수치와 프로토콜을 변경한 별도 판본이 아니다. 링크 변환 기록은 `provenance/document_links.json`에 있다.

## 포함과 제외

- 1안의 원자료·전처리·초기 실험·모든 후속 단계의 코드, 결과 CSV·배열, 체크포인트, 그림, 검증, 문헌 검토와 초안을 포함한다.
- 국내 제출 원고·v4 코드 및 감사 기록은 출발점을 설명하는 역사적 자료다. 최신 수정 결과나 최종 워크숍 제출본으로 간주하지 않는다.
- 2안·3안은 과거 보존 manifest의 참조 대상이어서 포함한다. 1안의 실험 수나 성과에 합산하지 않는다. 3안의 새 AI 학습은 진행하지 않았다.
- 원자료 복구의 추가 감사 자료는 `context/`에 있다. PROJ 검토는 이 자료가 현재 연구의 원자료가 아니라는 판별 기록이며, PROJ 자체의 원자료·전체 코드를 재배포하는 묶음은 아니다.
- Python 캐시 11개와 외부 논문 전체 PDF·추출 텍스트 8개는 제외했다. 해당 인용의 출처 링크와 검토는 연구 문서에 남겼다.
- 과거 삭제한 불필요 자료의 백업 압축본은 포함하지 않았다. 삭제 내역과 감사 기록은 남겼다.

따라서 누락된 역사적 링크 중 PROJ 전체 자료와 삭제 백업은 실행에 필요한 1안 입력이 아니다. 문서 사본은 해당 위치를 없는 링크로 연결하지 않고 역사적 미포함 참조라고 표시한다.

## 연구 결과와 포장 검증의 구분

기존 연구 검증은 96개 모델 학습, 통계 추론, 정보 시점과 후보 통제를 포함한다. GitHub 포장 검증은 원본과의 일치, 다른 경로의 원자료 전처리·수치 재계산, 새 CPU 환경에서의 저장 모델 재현, 문서 링크와 대용량 파일 전달을 확인한다.

파일 체크섬이 맞는다고 모든 연구 가정이 옳다는 뜻은 아니다. 이번에 새 GPU 실험, 새 기간 수집, 독립 외부 검증 또는 논문 제출을 한 것은 아니다. 재현해도 짧은 기간·동일 기간 반복 사용·가상 입력 변화라는 연구의 범위는 유지된다.

각 제공자의 원자료와 인용 저작물의 권리는 해당 권리자에게 있다. 이 저장소에 일괄적인 데이터 재라이선스를 부여하지 않는다.
