# 데이터, 가격 기준과 전처리

## 원자료

복구한 원자료 7개는 `research/data/raw data/`에 모두 있다. 각 파일의 SHA-256은 [복구 당시 manifest](../research/RECOVERED_RAW_DATA_MANIFEST.json)와 [현재 전체 manifest](../provenance/archive_manifest.json)에 기록한다. 별도의 API 재수집 없이 제공된 CSV에서 재현할 수 있다. 파일명에 적힌 날짜 범위와 실제 유효 관측 범위를 구분한다.

| 파일 | 내용 | 연구에서의 역할 |
|---|---|---|
| `binance_1h_2025-06-01_2026-03-19.csv` | Binance 시간봉 OHLCV | 해외 기준 가격·수익률·거래량, 최신 AI 입력 |
| `upbit_1h_2025-06-01_2026-03-19.csv` | Upbit KRW 시장 시간봉 OHLCV | 국내 코인·USDT 가격과 거래량, 최신 AI 입력 |
| `USDKRW.csv` | 환율 관측 | 국내 원고 가격 환산 및 시간대별 조건부 재계산 |
| `DXY.csv` | 달러 지수 관측 | 이전 거시 통제와 시간대 민감도 |
| `VIXY.csv` | VIXY 가격 관측 | 이전 변동성 관련 대용변수; VIX 현물지수와 구분 |
| `SPY US.csv` | SPY 관측 | 이전 수집·전처리 계보와 거래시간 확인 |
| `XAUUSD.csv` | 금 가격 관측 | 이전 외생변수 수집·전처리 계보 |

두 거래소 CSV는 각 6,983개 데이터 행과 헤더를 포함한다. 실제 timestamp 범위는 **2025-06-01 18:00 UTC~2026-03-19 16:00 UTC**이며 이는 시간봉 시작 시각이다. 값의 결측 여부와 최종 학습 표본 조건은 별도다. 최신 전처리는 시각에 한 시간을 더해 완료된 시간봉의 종료 시각으로 정렬한다.

거시 CSV는 수동으로 내보낸 자료이며 헤더 없는 형식·역순 시각·여러 가격 열·빈 행이 섞여 있다. 행의 종류를 확인하지 않고 일괄 `read_csv` 기본값으로 읽어서는 안 된다. Bloomberg 화면의 원 시간대는 확정되지 않았고, 통화가 KRW라는 사실만으로 KST라고 정하지 않았다. 조건별 해석은 [재계산 보고서](research/reanalysis_20260909/RESEARCH_REASSESSMENT_KO.md)를 따른다.

파생상품 지표 등 기존 입력은 `research/corrected_outputs/`와 `research/reference/original_v4/`의 계보에 있다. `corrected_outputs`라는 과거 폴더 이름이 현재 수정 완료를 뜻하지 않는다. 최신 AI 30개 특징에는 Bloomberg 거시 변수나 새로운 호가 깊이·주문 흐름이 포함되지 않는다.

## 가격 정의의 변경

이전 코드에는 `USDT_BINANCE_CLOSE`라는 이름의 거래쌍 방향 해석 문제가 있었다. USDCUSDT를 q로 사용할 때 가격 환산은 `U × q / F`이며 `U / (F × q)`와 다르다. 이전 국내 원고 목표의 재계산은 이 변경과 시간대 가정을 함께 구분한다.

최신 호가·AI 실험은 다음 상대가격 기준을 사용한다.

```text
b_i = 10000 × log(Upbit_USDT_KRW × Binance_i_USDT / Upbit_i_KRW)
mean5 = 다섯 코인의 b_i 평균
```

다섯 코인은 BTC·ETH·XRP·SOL·DOGE다. 이 식의 Binance 가격은 해당 코인의 USDT 표시 가격이다. 같은 시점의 거시 USDKRW 관측을 추가로 요구하지 않는 상대가격 비교다. USD 페그의 참괴리, 국내 원고의 기존 잔차, 직접적인 투자 수익률로 부르지 않는다.

## 최신 AI 입력 30개

전처리 구현은 [prepare.py](../research/option1_tick_learning_20260910/prepare.py), 후보 변화와 호가 계산은 [shared.py](../research/option1_tick_learning_20260910/shared.py)에 있다.

| 특징 | 개수 | 계산과 단위 |
|---|---:|---|
| `basis_{coin}` | 5 | 코인별 b_i, bp |
| `mean5`, `median5`, `dispersion` | 3 | 다섯 괴리의 평균·중앙값·표본 표준편차, bp |
| `offshore_return_{coin}` | 5 | Binance 가격의 한 시간 log 변화 ×100, % 단위 |
| `venue_volume_{coin}` | 5 | Upbit/Binance 거래량 비율의 자연로그 |
| `usdt_range` | 1 | Upbit USDT 고가/저가의 자연로그 |
| `usdt_volume_surprise` | 1 | 현재 log 거래량 − 과거 24시간 log 거래량 평균; 평균은 한 시점 지연 |
| `usdt_unchanged` | 1 | USDT 종가가 직전 종가와 같은지의 지시값 |
| `btc_vol24` | 1 | 과거 24시간 BTC 수익률 표준편차 |
| `hour_sin`, `hour_cos`, `weekend` | 3 | UTC 시간과 주말 특징 |
| `tick_bp_{coin}` | 5 | `10000 × log(1 + tick(price)/price)` |

입력은 실제 과거 24시간 ×30개 특징이다. 시간 인덱스를 한 시간 격자로 정렬하고, 입력 창과 미래 목표가 유한한 값으로 확보된 표본만 사용한다. 최신 AI 단계의 입력 창은 2025-08-02 이후부터 시작한다. 완성된 전체 배열은 **5,372×24×30**이다.

목표는 `현재 시각 + 실제 6시간`에서의 mean5다. 행을 여섯 칸 이동한 결과를 여섯 시간으로 간주하지 않는다. 한 시각에 모든 필요한 값이 없으면 단순히 미래값으로 채워 넣지 않는다.

## 가격 후보와 미래 정답

평균·최대 손실 학습의 후보는 원래 입력과 최신 한 시간의 다섯 코인 ±1호가, 총 11개다. 무작위 대조는 변화의 log 가격 크기를 보존하고 변화가 들어갈 코인을 섞는다. 모든 표준화 특징의 L2 크기를 같게 맞춘 것은 아니다.

후보를 만들 때 코인별 basis, 평균·중앙값·분산도·상대 호가 특징을 다시 계산한다. 미래 정답은 바꾸지 않는다. 평가에서는 최신 1·6·24시간 후보를 사용해 원래 입력 포함 총 31개 시나리오를 저장한다. ‘1·6·24시간’은 입력을 바꾼 범위이고 예측 시계는 모두 6시간이다.

## 출처와 재현의 범위

원자료는 사용자가 보유한 거래소 수집 CSV와 Bloomberg 내보내기 자료이며, 복구 경로와 당시 검증을 함께 보존했다. VIXY 식별과 기존 노트북 재현은 [원자료 감사](context/audit_20260908/raw_data_review/REVIEW_KO.md)에 있다. 이 저장소는 각 제공자의 원자료에 새로운 포괄적 이용 허락을 부여하지 않는다.

새로운 장기 표본·실시간 API 수집기를 제공한 것은 아니다. 현재 확보된 자료에서 전처리와 결과를 재현하는 범위다. PROJ 자료는 별도 BTC 연구로 판정되어 최신 입력에 사용하지 않았다.
