# 워크숍 2안의 제한된 발생 경보 파일럿

## 선택 근거와 지위

워크숍 1안과 원자료는 보존한다. 이번 실험은 동일한 자료를 사용한 새로운 탐색적 목표이며, 2026년 1~3월은 이미 이전 연구에서 본 기간이다. 외부 검증 또는 사전등록이라고 표현하지 않는다. 사건 수 진단 후, 예측 성능을 보기 전에 아래 사양을 고정한다. 목표·모형 탐색으로 유리한 결과만 선택하지 않는다.

초기 후보였던 BTC·ETH 공통 하단의 3시간 연속 지속은 2025년 6~10월에 학습할 양성 사례가 0개다. 따라서 지속시간 예측을 이번 주 분석에서 제외한다. 변경 이유는 예측 성능이 아니라 학습 가능한 양성 사례의 부재다. 3/5, DOGE 제외 3/4 정의의 사건 수도 모두 보존한다.

## 고정 목표

각 기준 자산 i의 상대 괴리 b_i=10000 log[USDT_KRW/(coin_KRW/coin_USDT)]. BTC·ETH 각각의 2025년 6~10월 하단 10%를 임계값으로 동결한다. 같은 시각 두 괴리가 모두 각 임계값보다 낮으면 C_t=1이다. 이는 관측 기준 두 개의 일치이며 진정한 USDT 공정가격·달러 디페그·독립적인 확인 두 개가 아니다.

현재 C_t=0인 시점에, 앞으로 1,2,...,6시간 중 한 번이라도 C=1이 될 확률을 예측한다. Y_t=max(C_{t+1},...,C_{t+6}). 미래 여섯 시점이 모두 있어야 한다. 양성 여부와 무관하게 결과의 이용 가능 시점을 t+6으로 통일한다. 전체 시계에서 먼저 계산한 뒤 결측을 제거한다. 장기 지속·인과 전염과 다른 질문이다.

## 가설

H1: 여러 기준의 괴리와 그 일치·불일치 정보를 학습하면, 평균 괴리와 현물 상태만 쓰는 같은 AI보다 발생 확률 예측이 개선된다.

H2: 위 정보의 비선형 결합을 배우는 작은 LightGBM이 같은 입력의 규제 로지스틱, 가법 스플라인 로지스틱, 최근 발생 빈도보다 개선된다. 이것이 주 AI 기여다.

H3: 해외 파생 포지셔닝의 추가 가치는 직접 관측되는 현물 정보와 별도로 평가한다. 양의 효과를 전제하지 않는다.

## 고정 비교 사양

- LightGBM: 이진 log-loss, 7잎, 150그루, 학습률 .03, 최소 잎 100, L2=10, seed=20260909, 1 CPU.
- 로지스틱: 입력 학습표본 표준화, L2 C=.1, 2000회 한도.
- 가법 스플라인 로지스틱: 각 변수 3개 분위수 knot, 2차 spline, C=.1. 시점별 복잡한 상호작용을 제외한 비선형 기준선이다.
- 최근 28일 발생 빈도: 현재와 같은 C=0 조건, 결과를 이미 아는 과거 origin만 사용. 작은 Laplace 평활화.
- 최근 28일 조건부 발생 빈도: 과거 24시간 C 발생 수가 0 / 1 / 2개 이상인 동일 상태, 최소 과거 30개가 없으면 전체 28일 빈도로 후퇴.
- 입력 local: 1안의 평균 괴리·BTC 수익/변동성·시간·현물 상태 19변수.
- 입력 reference: local + 개별 자산 괴리 5개 + BTC/ETH 문턱까지의 최대·최소 거리 + 5개 하단 개수 + 과거 6/24시간 공통 사건 수 + 평균-중앙값/평균-BTC 차이 + DOGE 및 USDT 1원 변화의 bp 민감도 2개. 마지막 두 개는 전 기간 일관된 산술적 1원 가격 변화이며 실제 역사적 최소호가로 부르지 않는다.
- 입력 full: reference + 1안의 해외 파생 7변수.
- local/reference/full의 동일 origin 비교. spline은 reference만. 총 7개 학습 모형과 2개 빈도 기준선.
- 각 모형 raw와 월별 최근 28일 확률 절편 보정도 함께 보존. 보정은 이전에 발행되고 target_time<해당 월 시작인 예측·라벨만 사용, 최소 100개. 1안과 마찬가지로 보정 효과와 AI 효과를 분리.

## 시간 분리와 평가지표

2025년 11월부터 월별 확장 학습, 각 월 시작보다 target_time이 엄격하게 과거인 라벨만 적합. 11~12월은 시계열 예측 및 보정 준비, 2026년 1~3월 평가. 하이퍼파라미터 검색은 하지 않는다. 암호자산 봉 종가는 봉 시작+1시간 이후, 파생 자료는 기존 보수적 +5분 이용시점과 as-of 정렬을 따른다.

주 지표 Brier score, 보조 log-loss / AP / AUC / 평균 예측확률과 실현빈도. 정확도는 사용하지 않는다. 동일한 미래 발생을 여러 origin이 예측하므로 시점 수를 독립 사건 수로 해석하지 않는다. 5일 달력 블록 bootstrap 1999회, 95% 구간, 주 세 비교(tree reference cal vs logistic reference cal / spline reference cal / recent28) Holm 보정. 추가 입력 비교는 탐색적이다. 월별 방향 및 1/10일 블록을 확인한다.

파일럿 통과는 reference tree의 Brier가 위 세 기준 모두보다 3% 이상 낮고, 세 paired 개선량의 5일 구간 하한이 0 초과 및 Holm p<.05, 각 기준 대비 3개월 중 2개월 이상 개선일 때다. 3%는 연구 운영상 기준이며 문헌 공인 규칙이나 검정력 보장이 아니다. H1/H3는 그 여부를 따로 보고한다. 통과하지 않으면 AI 우위를 주장하지 않고, 큰 신경망으로 성공할 때까지 탐색하지 않는다.

이 파일럿만으로 실제 경보 효용은 입증하지 않는다. 통과할 때만 검증기간에서 고정한 경보 정책, 중복 6시간 알림 억제, 사건별 사전 경보율·오경보/일·동일 경보 부담 비교, 두 대체 기준 목표, 입력 제거와 오류 사례 분석을 후속으로 수행한다. 경보 효용 실패 시에도 제출 주장의 강도를 낮춘다. 현 단계에서 매매 손익·유동성 원인·최초성은 평가하지 않는다.
