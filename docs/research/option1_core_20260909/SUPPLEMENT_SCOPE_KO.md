# 보조 진단 범위

주 사전 추세·통제 회귀와 경제적 계수 비교 결과를 본 뒤 작성했다. 주 사양·Holm 검정군은 바꾸지 않는다. 원 실행 사양에서 보조로 허용한 가격 수준 통제를 모든 14·28·42일 창, ETH·XRP·SOL 비교, controlled·controlled_trend 사양에 동일하게 추가한다. DOGE와 비교 자산의 일평균 log 원화 가격 두 변수를 넣고 기존의 동일한 재표집 가중치를 사용한다. 좋은 결과만 고르지 않는다. 시장 통제나 가격 자체가 제도에 반응할 수 있으므로 인과 식별이 아닌 조건부 민감도다.

동시에 원가격 범위를 확인해 28일 전후 실제 상대 호가 크기와 가격 격자 부합률을 계산한다. 공지의 신규 주문 격자이며, 개편 전 주문이 이후에도 체결될 수 있어 모든 종가의 강제 조건으로 보지 않는다. 이동 창 비교의 분포·순위는 기술통계로만 보고한다.
