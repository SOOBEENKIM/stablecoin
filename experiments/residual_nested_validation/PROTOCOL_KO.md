# 기존 자료만 사용하는 잠금·중첩 시간순 검증

## 목적과 지위

사용자 지시에 따라 추가 자료를 수집하지 않는다. 2025-06~2026-03의 기존 원자료와 기존 잔차 연구를 유지한다. 이 기간은 이전 연구에서 이미 사용했으므로 **새로운 독립 검증 또는 보지 않은 최종 테스트라고 부르지 않는다.** 이전 평가 결과가 연구자의 설계 선택에 영향을 미친 이력은 사후 재분할로 제거할 수 없다.

이번에 바로잡는 것은 현재 실행에서 **모델 계열·설정 선택까지 과거 내부 구간으로 이동시키고, 월별 외부 결과는 선택에 쓰지 않는 것**이다. 기존 결과를 보고 QRF를 승자로 고정하지 않고 선형을 포함한 여섯 계열에서 정해진 알고리즘이 선택한다. 이것은 이전 QRF의 9.10%를 재입증하기 위한 유리한 조합 찾기가 아니다. 성적이 나쁘거나 선형이 선택돼도 그대로 기록한다.

## 고정 데이터와 외부 평가

- 입력은 기존 7개 원자료 파일의 SHA256으로 고정한다. 날짜, 결측, 환율/글로벌 가격 환산, 변수 정의, 표본을 새로 변경하지 않는다.
- 주 조건: available_macro/EQ/실제 1h 뒤 잔차 q10. CAP/PCA 및 strict/EQ를 보조 조건으로 유지한다.
- 외부 평가는 기존과 같은 **2025-12-01~2026-03-19**, 월별 네 블록이다. 2025년 11월은 과거 오차 보정 준비 구간이다. 목표는 관측행 한 칸 뒤가 아니라 실제 1시간 뒤이며 학습 target_time은 검증 시작보다 엄격히 이전이다.
- 주 EQ의 기존 1,088개 시점과 strict EQ의 기존 467개 시점을 확인한다. 의도하지 않은 표본 변화가 있으면 점수 공개 전에 중단한다. 목표가 다른 잔차 정의끼리 손실 크기로 승자를 고르지 않는다.

## 두 단계의 시간 분할

각 외부 월 M에 대해 직전 3개월 M−3, M−2, M−1을 내부 검증 월로 사용한다. 각 내부 월의 모델은 그 월보다 이전 자료에서만 잔차 분해·입력/목표 표준화·모델을 학습한다. 내부 월별 순차 예측의 손실 합/관측 수 합으로 후보를 비교한다. 각 내부 월의 잔차도 그 월 이전에서 추정하므로 외부 월 직전까지 학습한 잔차를 내부 과거에 소급해 쓰지 않는다.

예: 2026년 1월 평가 모델은 2025년 10·11·12월의 내부 예측을 비교해 선택한다. 10월 내부 예측은 9월까지 학습하고, 11월은 10월까지, 12월은 11월까지 학습한다. 선택 후 12월 말까지 재학습하고 1월을 평가한다. 1월 결과를 보고 1월 모델을 다시 선택하지 않는다.

앞선 외부 월이 시간이 지나 뒤 월의 내부 자료가 되는 것은 허용한다. 이는 사전에 정한 순차 갱신 절차이며 사람이 외부 성적을 보고 규칙을 바꾸는 것과 다르다. 외부 전 기간 예측 완료까지 성적을 출력하지 않는다.

## 후보와 비교 대상

입력은 base와 history 두 조건이다. 후보는 기존 코드의 선형·상호작용·스플라인·분위수 부스팅·QRF·문턱 분위수 회귀다. 각 계열의 기존 세 설정×학습 전체/90일×목표 수준/변화량(12개)을 쓰며, 문턱 계열은 기존 두 경계×세 정규화×두 학습창×두 목표표현(24개)을 쓴다. 총 **84개 후보/정보 조건**이다. QRF는 150트리이며 잎 관측의 가중 경험분포 분위수를 사용한다.

세 내부 월 모두 유효한 후보만 선택할 수 있다. 문턱 구간 학습 표본 40 미만인 후보는 그 내부 월에서 무효로 기록하고 다른 월의 좋은 점수만으로 살리지 않는다. 코드 오류·예상하지 않은 예외를 성적이 나쁜 후보 탈락으로 숨기지 않는다. 동점은 잠근 후보 순서로 정한다.

외부에서 평가하는 네 절차:

1. `selected`: 선형을 포함한 전체 84개에서 내부 선택.
2. `linear`: 선형 계열의 12개에서 같은 내부 선택.
3. `threshold`: 문턱 계열의 24개에서 같은 내부 선택.
4. `qrf`: QRF 계열의 12개에서 같은 내부 선택. 이전 대표 모델을 동일 절차로 비교하기 위한 보조 결과다.

선택은 기본 seed 하나로 한다. 주 EQ 외부 모델은 고정한 네 seed로 실행하고 시점별 손실 평균을 사용한다. 다른 조건은 첫 seed다. 난수를 독립 시계열 표본처럼 4배로 세지 않는다. 선형·문턱처럼 결정론적 모델도 같은 표기로 반복되지만 표본 수는 증가하지 않는다.

## 보정과 주 판정

각 절차/정보 조건/seed별로 결과가 이미 알려진 과거 **원예측 오차**의 최근 60개(최소30개, 최대90일) q10을 더한다. 선택 모델 계열이 월별로 바뀌어도 동일한 선택 절차의 순차 예측 오차를 사용한다. 현재 또는 미래 정답을 보정에 쓰지 않는다. 일반적인 시간 의존하의 conformal 보장으로 부르지 않는다.

주 조건의 보정 후 세 비교를 미리 고정한다: selected-history 대 linear-history, selected-history 대 threshold-history, selected-history 대 selected-base. 월별 층화 5일 달력 블록 1,999회·95% 조건부 구간·중심화 양측 p값을 구하고 세 비교에 Holm을 적용한다. 개선율>0, 구간 하한>0, Holm p<.05인 경우에만 이번 조건부 검정에서 지지됐다고 표시한다. 이 표기도 새 독립 자료에서의 확증을 의미하지 않는다.

1/10일 블록, 보정 전, 월별·seed별 손실, 하회율, CAP/PCA/strict, qrf 절차, 선택된 모델 계열과 설정을 모두 보고한다. 보조 결과로 주 판정의 실패를 덮지 않는다. 예측 비교의 블록 구간은 학습된 전체 순차 예측을 고정하며, 모든 모델 선택을 재학습한 부트스트랩 또는 인간의 이전 탐색에 대한 완전한 보정이 아니다.

## 변경 통제와 테스트

설계·실행 코드·의존 코드·기존 입력·패키지 버전을 해시로 잠근 뒤 Git에 커밋/push한다. 그 다음 내부 후보 학습과 외부 예측을 실행한다. 전체 예측의 해시를 기록한 뒤 단일 평가 개봉 기록을 만든다. 같은 출력의 재현은 가능하지만 새로운 검증으로 세지 않는다. 결과를 본 뒤 설정을 바꾸고 같은 실행이라고 부르지 않는다.

합성 자료로 다음을 먼저 검증한다: 세 내부 월 선택 규칙, 무효 후보 처리, 외부 손실/정답이 선택 함수의 인수가 아님, 시간 분할의 경계, 미래 정답 변경이 이전 예측 보정에 영향을 주지 않음, 잠금 변경 및 재개봉 차단. 실행 후 내부 후보 수·실제 학습/목표 시각·평가 시점/목표 일치·월별 선택 이력을 감사하고 일부 실제 모델을 재학습해 저장 예측을 대조한다.

## 연구 결론의 범위

이 분석으로 보고할 수 있는 것은 **기존 표본에서, 과거 자료만으로 모델을 선택하는 고정 절차가 이어지는 구간에서 보인 성능**이다. 기존 반복 평가의 선택 문제를 알고리즘 수준에서 줄이지만 연구자가 이미 같은 기간을 봤다는 사실을 제거하지 못한다. 추가 자료를 사용하지 않는 조건에서 그 사실까지 해결됐다고 주장하지 않는다. 성능이 개선돼도 국내 투자자 레버리지의 인과효과나 가격 조정 메커니즘이 자동으로 입증되는 것은 아니다.
