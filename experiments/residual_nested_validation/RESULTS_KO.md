# 기존 자료의 잠금·중첩 시간순 검증 결과

**추가 데이터를 수집하지 않고, 모델 계열과 설정을 과거 세 달에서만 선택하도록 고정해 다시 실행했다. 이 선택 절차의 주 EQ 예측손실은 선형보다 10.65% 낮았다. 문턱 모형 대비 우위와 포지셔닝의 추가 효과는 미리 정한 주 판정 기준을 통과하지 못했다.**

이번 실행의 사후 모델 변경과 외부 월 성적에 의한 모델 선택은 차단했다. 그러나 같은 기간을 연구자가 이전에 검토한 이력은 남는다. **중첩 시간순 검증을 새 독립 데이터 검증으로 바꿔 부르지 않는다.**

## 1. 실행 전에 무엇을 고정했는가

설계·소스·입력·패키지 버전의 해시를 [LOCK.json](LOCK.json)에 저장했고, [커밋 519682a](https://github.com/SOOBEENKIM/stablecoin/commit/519682a230400f463ac88b7de90d81b1a6469b11)를 GitHub에 push한 뒤 실행했다. 이전 원고 재현과 두 ML 실험, 경제적 해석 검증은 수정하지 않았다.

| 항목 | 이번 규칙 |
|---|---|
| 데이터 | 기존 원자료 7개, 해시 고정; 추가 수집·공급자 교체 없음 |
| 주 평가 | available_macro/EQ, 실제 1시간 뒤 잔차 q10, 2025-12~2026-03-19 |
| 내부 검증 | 각 외부 월 직전 3개월의 순차 예측. 각 내부 월도 그 월 이전 자료로만 학습 |
| 후보 | 선형·상호작용·스플라인·부스팅·QRF·문턱, 총 84개/정보 조건 |
| 선택 | 세 내부 월의 총 손실/관측 수가 가장 작은 후보. 외부 월 성적은 선택 함수에 전달하지 않음 |
| 기준선 | 선형과 문턱도 같은 세 내부 월에서 각각 설정을 선택 |
| 난수 | 주 EQ 네 개를 고정하고 시점별 손실 평균; 나머지 조건은 첫 난수 |
| 보정 | 이미 정답이 관측된 최근 원예측 오차 60개만 사용 |
| 주 비교 | 선택 절차 대 선형, 대 문턱, 포지셔닝 추가 효과의 세 가지 |
| 판정 | 양의 개선, 5일 블록 95% 구간 하한>0, 세 비교의 Holm p<.05 모두 충족 |
| 결과 개봉 | 전체 예측 생성·해시 고정·무결성 검증 후 단일 개봉 기록 생성 |

외부 평가 시점과 목표는 이전 결과와 같음을 코드로 확인했다. 주 분석은 **1,088시점·78일**, strict/EQ는 **467시점**이다. 11월은 보정 준비 구간이며 네 평가 월 점수에는 포함하지 않는다.

선택된 모델이 다음 달에 바뀌는 것은 사전에 정한 자동 갱신이다. 사람이 그 달의 결과를 보고 같은 달의 모델을 바꾸는 것은 허용하지 않았다. 3월 평가 기간이 짧다고 제외하거나 유리한 날짜만 고르지 않았다.

## 2. 실제로 선택된 모델

주 EQ에서는 base와 history 모두 아래 계열이 과거 내부 점수로 선택됐다. 선형도 후보에 들어 있었지만 이 네 월의 주 조건에서는 선택되지 않았다.

| 평가 월 | 선택된 계열 | 학습 범위 | 학습할 목표 |
|---|---|---|---|
| 2025-12 | QRF | 이전 전체 | 잔차 변화량 |
| 2026-01 | 분위수 부스팅 | 이전 전체 | 잔차 변화량 |
| 2026-02 | QRF | 이전 전체 | 잔차 변화량 |
| 2026-03 | QRF | 최근 90일 | 잔차 변화량 |

변화량을 학습한 뒤 현재 잔차를 더해 최종적으로 같은 미래 잔차 수준의 q10을 예측한다. QRF 설정은 깊이 제한 없음·최소 잎 20·max_features=.7·150트리, 1월 부스팅은 깊이2·150트리·최소 잎20·학습률.03이다. 전체 월·정보·잔차 정의·관측 조건의 선택 이력은 [algorithm_choices.csv](results/algorithm_choices.csv)에 있다.

`qrf`라는 별도 비교 절차는 계열만 QRF로 제한하고 설정은 같은 세 내부 월에서 선택한다. **이 보조 절차가 주 선택 절차보다 잘 나온다고 주 결과를 교체하지 않는다.**

## 3. 주 결과

`history`는 기존 시장·잔차 입력에 포지셔닝 수준과 변화량을 추가하고, `base`에는 포지셔닝이 없다. 주 지표는 과거 오차 보정 후 q10 pinball loss이며 작을수록 좋다. 개선율은 수익률·가격 하락률 또는 RMSE 감소율이 아니다.

| 예측 절차 | 정보 | 평균 손실(bp) | 예측 하위 경계 하회 비율 |
|---|---|---:|---:|
| 선형 내부 선택 | base | 1.829378 | 9.19% |
| 선형 내부 선택 | history | 1.892994 | 8.73% |
| 문턱 내부 선택 | base | 1.743133 | 9.19% |
| 문턱 내부 선택 | history | 1.748325 | 9.74% |
| 전체 후보 내부 선택 | base | 1.699977 | 9.95% |
| **전체 후보 내부 선택** | **history** | **1.691431** | **10.09%** |
| QRF 계열 내부 선택(보조) | base | 1.684851 | 10.27% |
| QRF 계열 내부 선택(보조) | history | 1.678514 | 10.25% |

| 사전에 정한 주 비교 | 손실 개선율 | 95% 조건부 구간 | Holm p | 판정 |
|---|---:|---:|---:|---|
| 선택-history 대 선형-history | **10.65%** | **7.14~14.00%** | **0.0015** | 이번 조건부 검정에서 지지 |
| 선택-history 대 문턱-history | 3.25% | −1.04~8.78% | 0.4030 | 지지 못함 |
| 선택-history 대 선택-base | 0.50% | −0.50~1.44% | 0.4030 | 지지 못함 |

블록 구간은 고정된 순차 예측에 조건부다. 월별 층화 달력 블록 1,999회이며 전체 후보 학습을 다시 하는 부트스트랩도, 과거 모든 연구자 선택에 대한 보정도 아니다. 구간과 p값은 각각 percentile 방식과 중심화 방식이어서 수학적으로 정확히 역관계인 검정으로 취급하지 않는다.

주 선택 절차의 선형 대비 개선은 네 seed에서 **10.44~10.89%**였다. 선택-base 대 선형-base도 **7.07%[3.74, 10.37]** 개선됐다. 따라서 예측 개선은 포지셔닝이 없어도 나타난다. 두 정보 조건은 각각 모델을 선택하므로 history−base는 **정보를 추가한 선택 절차의 증분 효과**이며, 동일 계수를 고정한 변수의 인과효과가 아니다.

이전 보고의 9.10%에서 10.65%로 “모델이 더 좋아졌다”고 단순 비교하지 않는다. 이번에는 선형을 포함한 모든 비교 대상의 내부 선택 절차가 직전 한 달에서 세 달로 바뀌었다. 이전 선형-history 손실은 1.823233, 이번에는 1.892994이므로 분모도 다르다.

## 4. 월별 결과와 불리한 결과

| 평가 월 | 선택-history 손실 | 선형-history | 문턱-history |
|---|---:|---:|---:|
| 2025-12 | 1.631570 | 1.928381 | 1.767746 |
| 2026-01 | 1.443728 | 1.630453 | **1.395312** |
| 2026-02 | 1.881750 | 2.143904 | 1.929439 |
| 2026-03 | 1.881836 | **1.872377** | 1.982131 |

선형 대비 개선은 **3/4개월**이다. 3월에는 선택 절차가 약간 나빴고, 1월에는 문턱 모형이 더 좋았다. 이를 제외하고 전 기간에서 일관되게 우월했다고 표현하지 않는다. 1월에 과거 내부 점수로 선택된 부스팅을 외부 성적이 더 좋은 QRF로 사후 교체하지 않았다.

보정 전 원예측에서는 선택-history의 선형 대비 개선이 **10.18%[4.00, 16.82]**였다. 문턱 대비 5.98%, 포지셔닝 추가 0.21%였다. 보정 전의 유리한 문턱 비교로 주 분석의 보정 후 판정을 대체하지 않는다. 보정 전 하회율은 선택-history 18.52%로 명목 10%와 차이가 있어 보정의 역할도 별개로 봐야 한다.

## 5. 정의·표본에 대한 민감도

모두 보정 후, 각 조건 내 동일 시점·동일 잔차 목표로 비교했다. 보조 조건은 기본 seed 하나이며 주 EQ는 네 seed 평균이다.

| 조건 | 선택-history 대 선형-history | 대 문턱-history | 포지셔닝 증분 |
|---|---:|---:|---:|
| 주 EQ | +10.65% [7.14, 14.00] | +3.25% [−1.04, 8.78] | +0.50% [−0.50, 1.44] |
| CAP | +6.62% [2.10, 10.79] | +3.64% [0.83, 6.60] | −1.19% [−2.82, 0.35] |
| PCA | +12.17% [8.69, 15.51] | +4.29% [0.29, 9.87] | +1.62% [0.51, 2.60] |
| strict/EQ | +8.24% [2.93, 13.44] | **−2.51% [−7.79, 2.78]** | **−4.90% [−9.50, −0.69]** |

선형 대비 개선은 네 조건의 점추정과 조건부 구간에서 유지됐다. 문턱 대비 우위는 엄격한 표본에서 역전됐다. 포지셔닝은 PCA에서 양수, strict/EQ에서 음수이므로 정의·관측 조건을 넘어 일관된 기여라고 부를 수 없다. PCA의 유리한 결과로 주 EQ의 실패를 대체하거나, strict의 음수로 포지셔닝이 경제적으로 무관하다고 결론 내리지 않는다. 모든 1/5/10일 블록·원예측·seed별 결과를 CSV로 공개했다.

## 6. 어떤 문제가 해결됐고 무엇이 남는가

**이번 실행에서 관리한 문제:** 특정 외부 월의 결과를 보고 그 월에 사용할 계열·설정을 선택하지 않는다. 후보의 비교와 선택은 세 내부 월에서만 이뤄지고, 학습·검증 경계에 걸치는 정답을 제외한다. 잠금 이후 모델과 판정 기준을 바꾸지 않았고 불리한 결과도 포함했다.

**기존 자료만으로 없앨 수 없는 문제:** 같은 평가 기간의 과거 결과를 연구자가 이미 확인했다는 사실이다. 이번 후보 계열과 검증 설계도 그 지식이 있는 상태에서 정했다. 새 데이터 없이 이 실행을 독립 확증이라고 주장할 수 없다. 이 사실과 각 모델이 그 시점의 미래 정답을 학습하지 않았다는 사실은 별개다.

모델 선택 단계 자체의 과적합과 평가 편향을 구분해야 한다는 방법론적 배경은 [Cawley & Talbot (2010)](https://www.jmlr.org/papers/v11/cawley10a.html)과 연결된다. 이번 설계는 시간 순서와 모델 선택을 분리하지만, 그 논문을 근거로 모든 사후 탐색이 제거됐다고 주장하지 않는다.

원고에 사용할 수 있는 결론:

> 공통요인 조정 후 한국 USDT 잔차의 1시간 하위 분위수를 예측할 때, 모델 계열과 설정을 과거 세 달의 순차 검증으로 선택한 절차는 기존 표본의 이어지는 평가 구간에서 선형 기준선보다 낮은 손실을 보였다. 그러나 문턱 기준선에 대한 우위와 포지셔닝의 증분 정보는 주 분석에서 확인되지 않았다. 따라서 결과는 고정된 시간순 선택 절차의 예측 유용성을 지지하지만, 새로운 독립 기간에서의 확증이나 포지셔닝의 경제적 원인 입증으로 해석하지 않는다.

앞선 가격 경로·변수군 제거 결과는 [경제적 해석 검증](../residual_economic_validation/RESULTS_KO.md)에 보존돼 있다. 이번 작업은 모델 선택과 평가 절차를 점검한 것이며, 새로운 가격 조정 메커니즘을 입증한 추가 실험으로 세지 않는다.

## 7. 실행 감사

- 실행 전 합성 무결성 테스트 **6개 통과**.
- 내부 후보 비교 **4,704건**, 무효 후보 **0건**, 외부 실제 모델 학습 **232회**, 경고 **0건**. 중복 후보가 선택된 절차는 같은 외부 학습을 재사용한다.
- 모든 **280개 절차/정보/월/seed 선택 기록**을 내부 점수에서 다시 계산해 일치 확인.
- **56개 보정 계열** 재현 및 미래 정답 교란 테스트 통과. 최대 보정 차이 1.43×10⁻¹⁴bp 미만.
- 1월 네 조건×두 정보의 모든 절차·seed 실제 모델을 재학습한 예측 차이는 3.56×10⁻¹⁵bp 미만.
- 기존 평가 시점·잔차 목표 동일, 실제 1시간 목표, 내부 검증의 월 경계 목표 제외, 학습/분해 시각 검사 통과.
- 검증 진입점의 과거 `run.py` 이름 충돌은 점수 개봉 전에 경로를 복원하는 보조 호출로 처리했다. **잠근 모델·분석 소스와 예측은 변경하지 않았다.** 실패 로그와 성공 로그, 보조 호출의 별도 해시를 [실행 기록](EXECUTION_NOTES_KO.md)에 남겼다.

예측 해시 고정과 점수 개봉은 각각 [PREDICTIONS_SEALED.json](results/PREDICTIONS_SEALED.json), [SCORES_OPENED.json](results/SCORES_OPENED.json)에 있고, 수치 검증은 [VERIFICATION.json](results/VERIFICATION.json)에 있다. 기록 시각은 UTC이며 연구 날짜 2026-09-25는 한국시간이다.
