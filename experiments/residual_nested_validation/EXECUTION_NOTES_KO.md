# 실행 중 발견한 검증 진입점 충돌

외부 예측 전체를 생성하고 해시를 봉인한 뒤, **평가 점수 개봉 이전**의 재현 검증 진입점에서 import 오류가 발생했다. `nested`가 불러온 기존 모듈은 과거 코드 디렉터리를 Python 탐색 경로 앞에 추가한다. 그 디렉터리에도 `run.py`가 있어 검증 스크립트의 `from run import outer_job`가 의도한 새 실행기 대신 과거 실행기를 찾았다.

모델·선택·평가 설계, 원자료, 잠근 소스와 예측 파일은 수정하지 않았다. 의존 모듈을 먼저 불러온 뒤 현재 디렉터리를 탐색 경로 앞으로 복원하는 검증 전용 진입점으로 실행했다. `run`과 `verify_results`의 실제 경로를 확인하고 원래 검증 함수를 그대로 호출한다. 같은 동작을 재현하는 파일이 `verify_locked.py`다.

이 파일은 최초 잠금 이후 추가한 **검증 호출 보조 코드**이므로 최초 `LOCK.json`에 포함돼 있었다고 주장하지 않는다. 별도 `VERIFICATION_LAUNCHER.json`에 해시·추가 시각을 기록했다. 원래 검증 함수 안에서 최초 잠금의 모델·분석 소스 해시를 계속 검사한다. 평가 성적을 보고 수정한 모델 변경이 아니다. 최초 오류 로그와 성공한 호출 로그를 모두 보존한다.
