# 잔차 상태를 반영한 위험 경계 보정: 결과 열람 전 고정 설계

## 목적과 주장 범위

기존 시장 공통요인 분해와 12시간 후 USDT 잔차 하위 10% 분위수 예측을 유지한다. (A) ML이 공정하게 보정된 선형·문턱형·경험분위수 기준선보다 유용한지, (B) 잔차 수준과 변동성을 반영한 보정이 기존 경계와 비교해 유용한지 구별한다. ML의 모든 월·지표·잔차 정의에서 승리를 요구하지 않는다. 3월은 진단 기간이며, 결과를 보고 3월에 맞춰 후보를 추가하거나 다시 선택하지 않는다. 유리한 결과를 전제로 하지 않는다.

과거에 이미 확인한 동일 자료를 사용한다. 시간 순서와 월별 선택을 엄격히 지키지만 독립적인 새 표본 검증, 사전등록, 인과 식별 또는 투고 가능성을 보장하는 실험은 아니다. 아래 설계 고정은 **이번 추가 실험의 결과 열람 전 고정**을 뜻한다.

## 고정한 자료와 예측기

- 원본 `residual_12h_robustness` original/F, 정확한 12시간 라벨, 2025년 12월~2026년 3월 평가 509시점. 추가 수집 없음.
- EQ 주 분석; CAP(고정 공급량×가격 시총 대용치), PCA는 정의 변경 민감도. CAP를 실제 유통량 가중치라고 부르지 않는다.
- 기존 60개 선형·문턱·QRF·분위수 부스팅 후보와 `residual_decision_value`의 2개 경험 기준선을 그대로 사용한다. 기존 시드 20260925로 선택한다.
- ML 추가 3시드는 고정된 선택을 재학습한다. 시드별 손실·의사결정을 같은 시점에서 평균하며, 예측 앙상블 또는 표본 수 4배로 해석하지 않는다. 기존 원시 예측을 재사용하고 새로 필요해진 후보/시드만 재학습한다.
- 월별 학습 라벨은 월 시작보다 엄격히 과거이고, 보정 오류의 라벨 시각은 현재 예측 시각보다 엄격히 과거이다. 현재 시각에 도착하는 라벨도 제외한다. 90일보다 오래된 라벨은 제외한다.

## 7개 보정 규칙: 모든 모형에 동일 적용

오류는 `실제 미래 잔차 - 해당 후보의 원시 분위수 예측`이다. 오류의 경험 10% 분위수(역 경험분포)를 원시 예측에 더한다. 이전 예측 시점의 오류와 상태값은 당시 학습된 잔차 정의를 사용하며 이후 달의 분해로 재작성하지 않는다.

1. global60: 최근 유효 오류 60개. 기존 결과와 수치 일치 확인.
2. global180: 최근 180개. 단순 표본 확대 효과를 구별하는 비교군.
3. scaled180: 오류를 당시 잔차 변동성으로 나눈 뒤 분위수를 계산하고 현재 변동성을 곱한다.
4. local180: 최근 180개 중 잔차 수준·변동성 상태가 가까운 60개의 오류 분위수.
5. local_scaled180: 가까운 60개에서 3의 변동성 정규화를 적용.
6. local_shrink180: global180과 local180 보정량의 1/2 혼합.
7. local_scaled_shrink180: scaled180과 local_scaled180의 1/2 혼합.

변동성은 기존 e_rms72(최근 72시간 잔차 시간 변화 RMS), 분모 하한은 1bp로 고정한다. 거리는 잔차 수준과 변동성의 **각 예측 월 학습 표본 내 경험 누적순위** 2차원에서 유클리드 거리로 계산한다. 동률이면 더 최근 관측치를 먼저 택한다. 이웃을 선택할 때 오류 크기나 미래 결과를 사용하지 않는다. 180개 미만이면 이용 가능한 수를 쓰고, 60개 미만이면 모두 이웃이다. 30개 미만이면 보정 0으로 초기화한다. 실제 내부 평가 및 외부 평가에서는 모두 30개 이상이어야 한다.

이는 이질적 오차에 대한 경험적 국소·척도 보정이다. 엄밀한 localized conformal 또는 adaptive conformal inference 알고리즘을 복제한 것이 아니며 분포 무관/조건부 포함률 보장을 주장하지 않는다.

## 모형 선택과 보정 효과 분리

각 외부 평가 월마다 직전 3개월의 원점/라벨이 같은 월에 속하며 이미 관측된 내부 점수만 사용한다. 목적은 기존과 동일한 보정 후 pinball loss이다. 경보 비용, 3월 성적, 시드 평균을 보고 선택하지 않는다. 동률이면 후보 번호, 위 보정 순서로 선택한다.

- legacy: 기존 global60으로 후보 선택.
- fixed_model_selected_cal: legacy 후보를 고정하고 7개 보정만 내부 선택. 동일 원시 모형에서의 보정 효과.
- joint_selected: 후보×7개 보정 조합을 내부 선택. 실제 운용 절차 비교.
- global_window_selected: 후보×global60/global180만 선택. 상태 보정이 단순 이력 확대보다 유용한지 확인.

추가로 legacy 후보 각각에 7개 보정을 고정 적용한 결과를 모두 공개한다. 이 표에서 외부 평가 최우수 보정을 골라 주 결과로 바꾸지 않는다. 각 달 joint_selected가 전역 보정으로 돌아가면 그 사실도 공개한다.

## 성능·유용성·불확실성

주 지표는 하위 분위수 pinball loss와 기존 -10bp 잔차 변화 경보 비용이다. 경보는 `예측 미래 잔차 - 현재 잔차 < -10bp`, 사건은 실제 동일 변화가 -10bp 미만이다. 비용은 `0.1×오경보 + 0.9×미탐`; 이는 가정한 9:1 비용 비율이며 금전 손익이 아니다. -5/-20bp는 보조 지표다. 잔차 변화는 국내 USDT 가격 수익률과 같지 않다.

EQ 주 비교는 A: joint ML 대 joint 선형/문턱/무조건 경험/상태 경험의 4쌍×2지표(8개 Holm); B: ML 고정모형 보정 대 legacy, ML 공동선택 대 legacy, ML 공동선택 대 전역창 선택의 3쌍×2지표(6개 Holm)이다. CAP/PCA에도 같은 비교를 보고한다. 모든 정의를 합한 42개 Holm은 추가 민감도다. 하나의 종합 통과/탈락 조건을 만들지 않으며 주장별 효과 크기, 구간, 비교군을 명시한다.

동일 시점을 짝지어 월별 층화 원형 달력 5일 블록 부트스트랩 1,999회, 95% 구간을 사용한다. 1/10일 블록과 기존의 시간순 비중첩 표본을 보조 확인한다. 기존 설계/모형 탐색 전체의 선택 편향을 이 p값이 제거한다고 해석하지 않는다.

매월, 특히 3월 105시점을 별도 공개한다. 전체/월별 실제 분위수 하회율(목표 10%), 학습 표본으로 정한 잔차 3×변동성 2 상태별 하회율과 구간, 오경보·미탐 수, 평균 경계, 조건별 절대 보정오차를 보고한다. 희소 상태(30개 미만)는 표시하고 그 상태의 보장/안정성을 주장하지 않는다. 전체 또는 3월에서 모든 지표 개선을 요구하지 않으며, 보정이 좋아져도 예측손실/경보가 나빠지는 상충도 공개한다.

## 검증과 저장 순서

1. 상태 자료와 기존 원시 예측의 정확한 키·목표값 대조. 메타데이터가 없는 EQ 추가 시드는 검증된 원점/정의/월 키로 채운다.
2. 합성 시간 지연·미래 라벨 오염·거리 동률·척도·실제 기존 global60 재현 테스트.
3. 코드/설계/입력 SHA-256 잠금, 커밋 및 원격 브랜치 저장.
4. 전체 예측/내부 선택 저장 후 봉인. 독립 정수 시계·직접 정렬 분위수·독립 순위·선택 재계산, 추가 모형 표본 재학습 검증.
5. 검증 성공 후 외부 평가 성적 공개. 비용과 점수는 별도 산술 계산으로 재검증. 부정적·혼합 결과도 그대로 커밋한다.
