# 2단계: 어떤 정보가 잔차 하방 예측에 추가로 도움이 되는가

## 범위

사용자가 승인한 2단계 변수군 제거·재학습만 실행한다. 현재 잔차와 직전 실제 1시간 변화는 항상 유지한다. 기존 1단계 및 중첩 검증 결과를 변경하거나 3단계 경보/4단계 가격 경로로 넘어가지 않는다. 추가 수집 없이 이미 검토한 2025-06~2026-03 원자료를 사용하므로 탐색적 후속 분석이다. 새로운 독립 확인으로 부르지 않는다.

전체 입력 비교 대상은 기존 `residual_nested_validation`의 `selected/history` 저장 예측이다. 과거 세 내부 월에서 선형·상호작용·스플라인·부스팅·QRF·문턱 84개 후보를 선택한 절차이며, 외부 결과를 보고 QRF 전용 절차로 교체하지 않는다. 기존 선형 대비 약 10.65%와 1단계 비교 결과는 보존한다.

## 제거할 세 변수군

| 변수군 | 제거할 직접 예측 입력 |
|---|---|
| 글로벌 BTC 시장 | `btc_ret1`, `btc_vol24`, `downside24` |
| 국내 USDT 거래량 | `local_volume_surprise` |
| 환율·거시 | `fx_ret1`, `dxy_ret1`, `vix_ret1`, 확장 표본의 `vix_known_log`, `vix_known_age_hours`, `dxy_known_age_hours` |

환율·거시에서 관측 경과 시간까지 제거해 같은 자료의 직접 파생 입력을 남기지 않는다. strict 표본에는 경과 시간/알려진 VIX 수준이 원래 없으므로 실제 존재하는 세 변화율만 제외한다. 달력 입력 `hour_sin/hour_cos/weekend`와 포지셔닝 입력은 유지한다. 시장 그룹을 제거해도 BTC 파생상품 포지셔닝은 남으므로 '모든 BTC 관련 정보 제거'라고 말하지 않는다.

제거 변수로 만든 **상호작용도 함께 제거**한다. 기존 상호작용 후보는 downside24 등을 무조건 참조하므로 새 폴더에서 입력이 모두 존재하는 항만 만드는 구현을 사용한다. 모든 입력이 있는 경우 기존 구현과 정확히 같은 행렬·예측이어야 한다. 예를 들어 글로벌 BTC 그룹 제거 시 downside24와 곱한 항은 없어지지만 `e_now × account_log`는 유지한다. 삭제한 값을 0으로 채워 예측하는 것이 아니라 남은 입력으로 처음부터 학습한다.

**잔차의 분해/가격 환산에 쓰는 환율·공통요인은 그대로 유지**한다. 잔차와 다른 변수에 이미 해당 정보가 반영될 수 있으며, 이번 실험은 그 위에 추가한 직접 예측 변수군의 기여를 묻는다. 변수군의 경제 전체 효과를 제거하는 실험이 아니다. 거래량 지표는 호가 유동성, 가격 충격 또는 투자자 주문 방향을 직접 측정하지 않는다.

## 재학습과 모델 선택의 두 비교

1. **주 분석 `retuned`**: 각 그룹 제거 후 남은 입력으로 기존 84개 후보를 다시 학습한다. 각 외부 월 직전 세 내부 월의 총 손실/관측 수로 후보를 선택하고 외부 월 이전까지 재학습한다. 내부 월도 해당 월 이전에서만 잔차 분해와 입력·목표 표준화를 학습한다. 제거 조건에 따라 적합한 모델 계열/설정이 달라지는 것을 허용한다.
2. **보조 `fixed_full_spec`**: 그 월에 전체 입력 절차가 과거 자료로 선택했던 모델 계열·학습창·수준/변화량·정규화/트리 설정을 사용하되, 해당 그룹을 제외하고 계수/트리/스케일러는 다시 학습한다. '같은 설정'은 계수·트리를 그대로 두거나 달마다 하나의 모델을 고정한다는 뜻이 아니다. 랜덤포리스트의 특성 추출 개수는 같은 비율 설정이어도 남은 변수 수에 따라 바뀔 수 있다.

주 분석은 정보를 추가/제외한 **전체 예측 절차**의 비교이고 보조는 모델 선택 변화에 대한 진단이다. 둘 중 유리한 결과를 주 결과로 바꾸지 않는다. 모델이나 그룹을 외부 점수로 추가하지 않는다.

세 그룹 × 네 조건 × 일곱 내부 월 × 84개 후보 = 내부 후보 학습 7,056회 예정. 모든 후보가 세 내부 월에서 유효해야 선택 가능하며, 문턱 모형의 기존 최소 구간 표본 제한도 유지한다. 코드 오류나 예상 밖 예외를 불리한 후보 탈락으로 처리하지 않는다. 동점 규칙은 기존 후보 순서다.

## 동일 표본과 시간 순서

주 조건은 available_macro/EQ, 실제 1시간 뒤 잔차 q10, 2025-12-01~2026-03-19의 기존 1,088개 시점이다. CAP/PCA 각 1,088개, strict/EQ 467개는 보조 조건이다. 변수 제거로 결측 조건을 완화해 표본 수를 늘리지 않으며, 잔차 목표도 동일하게 유지한다. 각 학습 target_time과 잔차 분해 fit_end는 해당 평가 월 시작보다 엄격히 이전이어야 한다. 내부 검증의 다음 달 경계 정답도 제외한다.

11월은 보정 준비 기간이다. 모든 절차에 동일하게, 시점보다 엄격히 이전에 알려진 원예측 오차 최근60개(최소30, 최대90일)의 q10을 더한다. 그룹/선택 방식/seed별로 각각의 과거 오차를 사용한다. 원예측과 보정 후 결과를 모두 공개한다.

주 EQ는 기존 네 seed를 동일하게 사용하고 시점별 손실을 평균한다. 평균 예측을 새 앙상블로 쓰거나 시계열 표본 수를 4배로 늘리지 않는다. 보조 조건은 기존 첫 seed다.

## 지표와 판정

주 효과는 `제외 시 손실 증가율 = 100 × (L_without / L_full − 1)`이다. **양수면 해당 그룹을 넣었을 때 유용**, 음수면 이번 절차에서 제외한 쪽의 손실이 작다는 뜻이다. 분모는 전체 입력 손실이며 이전의 포함에 따른 개선율 `100 × (1−L_full/L_without)`와 다르므로 후자도 별도 열로 구분해 저장한다. 손실 증가율을 수익률, 하락 확률 또는 인과효과로 해석하지 않는다.

주 검정은 EQ/retuned/보정 후 세 그룹이다. 월별 층화 5일 달력 블록, 1,999회, 95% 구간, 중심화 양측 p, 세 그룹에 Holm 보정을 적용한다. 증가율>0, 구간 하한>0, Holm p<.05를 모두 만족할 때만 해당 직접 입력 그룹의 조건부 증분 예측 기여를 지지한다고 보고한다. 음의 유의한 차이도 숨기지 않지만 경제적 무관함/해로움의 증명으로 바꾸지 않는다.

1/10일 블록, 보정 전, 월별·seed별, 하회율, 고정 설정 재학습 및 네 조건을 모두 공개한다. 같은 예측을 고정한 블록 비교로 전체 선택 재학습이나 과거 인간 탐색에 대한 완전한 보정을 제공하지 않는다. 보조 조건은 주 EQ와 변수 가용성·표본/목표가 다르므로 차이의 원인을 분리 식별했다고 주장하지 않는다.

그룹을 하나씩 제거한 효과는 일반적으로 **가산적이지 않다**. 서로 대체하거나 함께 작용하는 정보가 있어 세 효과를 더해 ML 개선 10.65%를 배분할 수 없다. 비유의 결과도 그 정보의 총 경제적 가치가 0이라는 증거는 아니다. SHAP/단순 중요도 순위만으로 설명하거나 직접 인과효과를 주장하지 않는다.

## 검증 및 변경 통제

합성 테스트 → 입력·소스·환경·기존 예측/선택 해시 잠금 → Git commit/push → 전체 예측 봉인 → 실제 재학습/무결성 검증 → 점수 개봉 순서를 유지한다. 잠금 이후 결과를 보고 설계를 바꾸지 않는다.

테스트는 그룹 정의와 항상 유지할 입력, 제거 입력의 파생 상호작용 차단, 전체 입력에서 구 상호작용 구현과 일치, 삭제 입력을 훈련 자료에서 교란해도 재학습 예측 불변, 미래 정답 차단, 세 과거 월 선택 및 경계, 변화량 pinball 불변성, 변경 잠금/덮어쓰기 거부를 포함한다. 실행 후 모든 선택 재계산과 보정 재현, 실제 1월 네 조건×세 그룹×두 선택 방식×해당 seed 재학습, 원본 전체 입력 예측 일치, 실제 시계와 같은 목표/표본 여부를 검증한다. 전체 입력의 1월 모델도 네 조건에서 재학습해 새 적합 함수가 기존 결과를 재현하는지 확인한다.

## 방법론 참고와 적용 범위

- Williamson et al., JASA 2023, [A general framework for inference on algorithm-agnostic variable importance](https://arxiv.org/abs/2004.03683): 모든 입력과 관심 입력을 제외한 예측력 대비로 중요도를 정의하는 배경을 참고한다. **이번 실행은 그 논문의 oracle 중요도·효율적 추론·독립 표본 점근 이론을 그대로 구현한 것은 아니다.** 제한된 후보의 시간순 재학습 절차와 그 고정 예측에 대한 블록 비교다.
- Cawley & Talbot 2010, [On Over-fitting in Model Selection and Subsequent Selection Bias in Performance Evaluation](https://www.jmlr.org/papers/v11/cawley10a.html): 모델 선택과 성능 평가를 구분한다. 이번 내부 선택이 기존 평가 기간을 이미 본 이력까지 없애지는 않는다.
