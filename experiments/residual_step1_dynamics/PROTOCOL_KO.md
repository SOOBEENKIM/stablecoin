# 1단계: 단순 잔차 동학을 넘어서는 ML 예측 정보

## 범위와 지위

사용자가 승인한 4단계 중 1단계만 실행한다. 기존 중첩 검증의 ML 선택 절차와 선형·문턱 모형의 저장 예측을 그대로 사용한다. 추가 모델 탐색, 변수군 제거, 경보 성능, 실제 가격 구성요인 분석은 하지 않는다. 기존 선형 대비 약 10.65% 결과를 교체하지 않는다. 같은 과거 기간을 이미 보았으므로 이번 결과도 탐색적 후속 검증이며 새로운 독립 확인이 아니다.

## 비교모형: 하위 10% 분위수로 공정하게 비교

잔차 e는 bp 단위이며 목표는 실제 시계로 1시간 뒤의 e다.

1. **지속성 + 과거 하락 분포 (`persistence`)**: q(t+1)=e(t)+Q10_train[e(t+1)-e(t)]. 현재 수준을 그대로 예측하는 점예측을 하위 분위수와 비교하지 않는다. 과거 변화량의 경험 분위수로 하방 폭을 반영한다. 전체/90일 두 후보.
2. **잔차 수준에 따른 조정 (`ar_quantile`)**: q(t+1)=a+b e(t)를 직접 분위수 회귀로 추정한다. b=1인 지속성뿐 아니라 수준에 따른 복원/확대도 허용한다. 이를 '평균회귀를 허용하는 비교모형'으로 설명하되 조건부 평균의 평균회귀를 입증했다고 말하지 않는다. b를 유리하게 제한하지 않는다.
3. **조정 + 변동성 (`dynamics_vol`)**: 위 식에 직전 실제 1시간 잔차 변화, BTC 24시간 변동성, BTC 24시간 하락 제곱 평균을 추가한다. 변동성은 기존에 사용한 글로벌 BTC 시장 지표이며 USDT 잔차 자체의 변동성이나 호가 유동성이 아니다.

2·3번은 기존 선형 QuantileRegressor와 동일한 훈련 전용 X/y 표준화·정규화 alpha=0/.01/.05, 전체/90일, 수준/변화량 목표를 사용한다. 각 12개 후보로 두 표현의 정규화 차이까지 과거 내부 평가로 선택한다. 1번 2개를 합쳐 총 26개다. 계수는 원단위로 저장하되 경제적 인과효과로 해석하지 않는다.

기존 전체 변수 선형 및 문턱 모형은 고정된 저장 예측을 재사용한다. ML은 기존 `selected/history` 절차이며 결과를 본 뒤 더 좋았던 QRF 전용 절차로 교체하지 않는다. 주 EQ에서 네 seed의 **손실**을 시점별로 평균하고, 평균 예측을 새 앙상블로 평가하거나 표본을 4배로 늘리지 않는다. 결정론적 새 비교모형은 한 번 학습한다.

## 시간 순서와 동일 표본

기존 잔차 분해·원자료·정보 가용 시각·결측 마스크를 그대로 유지한다. 주 조건 available_macro/EQ의 1,088개 시점, strict/EQ 467개 시점을 정확히 맞춘다. CAP/PCA는 보조 조건이며 다른 잔차 정의의 손실 크기로 주 정의를 바꾸지 않는다.

각 평가 월 직전 3개월의 순차 내부 예측 손실 합/관측 수 합으로 각 비교 계열에서 후보를 선택한다. 각 내부 월에서도 그 월 이전 자료로 잔차 분해·표준화·학습한다. 다음 달 경계에서 알려지는 내부 정답은 제외한다. 선택 함수에 외부 점수/정답은 전달하지 않으며 세 내부 월이 모두 존재해야 한다. 동점이면 미리 정한 후보 순서다.

평가는 2025-12~2026-03-19이며 11월은 보정 준비 기간이다. 각 절차에서 해당 시점보다 엄격히 이전에 알려진 원예측 오차 최근60개(최소30, 최대90일)의 경험 q10을 더한다. 새 모형만 유리하게 보정하지 않고 기존과 같은 규칙을 쓴다. 미보정 결과도 전부 공개한다.

## 판정과 해석

주 비교 4개: ML 대 지속성, ML 대 잔차 수준 조정, ML 대 조정+변동성, ML 대 기존 문턱 모형. 보정 후 EQ 시점별 q10 pinball loss를 주 지표로 한다. 5일 달력 블록·월별 층화·1,999회 부트스트랩, 95% 구간 및 중심화 양측 p, 네 비교에 Holm 보정을 적용한다. 개선율>0, 구간 하한>0, Holm p<.05일 때만 해당 비교가 조건부로 지지됐다고 표시한다. 이전 선형 대비 10.65%는 기존 결과 재현용 보조 비교이며 이번 4개 주 검정과 구별한다.

1/10일 블록, 월별·seed별, 하회율과 그 블록 구간, 미보정 결과, CAP/PCA/strict 결과도 보고한다. 이 구간은 저장 예측을 고정한 조건부 비교이며 모든 모델 선택 재학습 또는 이전 연구자의 탐색을 보정한 구간이 아니다. 한 보조 조건만 골라 일반적 우위로 선언하지 않는다.

알려진 e(t)를 목표와 예측에서 함께 빼면 Δe와 그 q10이 되며 **pinball loss는 정확히 동일**하다. 번역 불변성을 수치로 검증하고 변화량 표현도 저장한다. 이는 추가 하락에 대한 해석을 명확하게 하는 것이지 새로운 성능 향상이나 경보 성공률 증거가 아니다. 기존 주 ML 선택 모델도 이미 변화량을 학습하는 후보를 선택했다.

단순 모형을 앞서면 '현재 잔차의 지속성 또는 제한된 조정·시장 변동성만으로 설명되는 예측보다 추가 정보가 있었다'고 말할 수 있다. 이것만으로 ML 알고리즘 자체가 정보량이 같은 모든 모형보다 우월하다고 하거나, 포지셔닝의 인과효과·수익성·실제 가격 조정 메커니즘을 주장하지 않는다. 문턱 대비 불확실하면 그대로 남긴다.

## 실행 통제와 검증

실행 전 합성 테스트 → 소스·7개 입력·기존 예측/설계/잠금 파일의 SHA256 및 환경 고정 → Git 커밋/push → 모든 예측 저장/봉인 → 검증 → 점수 공개. 기존 잠금 파일을 변경하지 않는다. 코드 오류가 발생하면 예측/개봉 여부와 변경을 기록하고 성능을 보고 설계를 고치지 않는다.

검증: 내부 경계·미래 점수 거부·후보 누락, 실제 단위 계수와 예측 일치, 학습 후 미래 정답 변경의 예측 불변성, 보정 미래 정답 교란, 목표/시점과 기존 예측 일치, 1월 모든 새 비교모형 실제 재학습, 모든 선택·보정 재계산, 수준/변화 pinball 일치. 완료 후 2단계로 자동 진행하지 않는다.

- 기존 문턱 모형의 정의와 선행연구 관계는 `../residual_economic_validation/PROTOCOL_KO.md`에 유지한다. 이번 단순 비교모형은 특정 김치프리미엄 논문의 정확한 재현이라고 주장하지 않는다.
