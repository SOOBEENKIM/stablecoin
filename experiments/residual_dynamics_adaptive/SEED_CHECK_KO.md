# QRF 난수 민감도: 주 결과 확인 후 진단

주 EQ/available_macro 결과에서 QRF의 선형 대비 개선은 9.63%, 포지셔닝 수준·변화량 전체 추가는 1.32%였다. 두 번째 효과가 작아서 150개 트리의 난수에 민감할 수 있다는 구체적 우려를 점검한다.

- 현재 선택된 월별 학습 창·표현·하이퍼파라미터는 고정한다. 후보 선택을 다시 하거나 좋은 seed를 선택하지 않는다.
- 원래 seed 20260925 외에 순서대로 20260926, 20260927, 20260928 세 개를 사용한다.
- EQ/available_macro/QRF, base/full/history, 11월 준비 구간과 12~3월 평가를 모두 재생성한다.
- 원예측과 보정 후의 선형(history) 대비 차이, history 대 base/full을 모두 보고한다. 네 seed의 평균과 범위도 공개한다.
- 이는 원래 전체 실험의 재실행이나 새로운 외부 검증이 아니다. 튜닝까지 다시 한 완전한 난수 민감도도 아니다. 고정된 선택 설정하에서 숲의 무작위성에 대한 후속 진단이다.
