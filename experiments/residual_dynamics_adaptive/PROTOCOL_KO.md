# 후속 실험: 정보 가용성·분포 변화·조건부 분포 학습

2026-09-25. 부모 커밋 `3a1e877`. 첫 ML 결과를 확인한 뒤 추가한 **탐색적 후속 설계**다. 기존 평가 기간을 재사용하므로 새 외부 검증이나 사전등록으로 부르지 않는다. 최초 실험·코드는 보존한다. 아래 후보를 새 예측 성능을 보기 전에 고정한다.

## 첫 실험에서 확인한 문제와 대응

1. 모든 모델에서 q10 하회율이 약 20~25%였다. EQ의 학습 q10은 12월 -8.45bp, 3월 -9.77bp인 반면 평가 월의 실제 q10은 각각 -14.02bp/-19.09bp였다. 분포 변화의 원인까지 식별한 것은 아니다. 과거 전체 학습과 최근 90일 학습, 과거 예측오차에 의한 온라인 경계 보정을 비교한다.
2. VIX/DXY의 새 관측이 없는 시점까지 제거해 많은 예측 기회를 버렸다. 실제 예측자는 이미 공개된 최근 값을 사용할 수 있다. **미래 목표·환율·코인 가격은 채우지 않고**, 예측 입력인 VIX/DXY만 이용 가능한 마지막 값과 관측 경과시간을 사용한다. 기존 엄격 표본도 별도로 유지한다.
3. 잔차의 현재 수준을 알고 있으므로 미래 수준 대신 변화량을 학습해 현재 잔차를 더하는 접근도 가능하다. 두 표현은 최종 평가 목표가 같다. 선형과 ML 모두 내부 검증에서 수준/변화량을 선택할 수 있게 한다.
4. 포지셔닝의 수준만으로 증분 정보가 없을 수 있다. 기존 묶음 외에 ACCOUNT_LS의 1h/24h log 변화, 펀딩의 8h 변화, OI의 24h log 변화를 추가한 정보 조건을 비교한다.

## 가격·잔차·표본

- 이전 `residual_dynamics_ml/data.py`의 가격, EQ/CAP/PCA, 순차 회귀 잔차, NY+1h 거시 가정, 실제 1h 목표를 그대로 사용한다. 분해 계수/PCA는 매월 이전 전체 자료에서 추정한다. 예측모형의 90일 학습 후보가 평가 목표 자체를 바꾸지 않는다.
- `strict`: 이전의 새 거시 관측 <60분 조건. 주 평가 467개와 목표가 일치하는지 검사한다.
- `available_macro`: 환율/가격/포지셔닝 조건은 유지. VIX/DXY만 과거 이용 가능 값(최대 96시간)을 연결하며 경과시간, log VIX 수준, KST 시각 sin/cos/주말을 추가한다. `*_ret1`은 이 마지막 이용 가능 값의 시계열 변화로 정의하며 새 값이 없으면 0이다. 이는 미관측 현재 VIX 가격을 만들어낸 것이 아니다. 거시 관측 시각의 NY+1h는 가정으로 남는다.
- 결과를 보기 전 표본 점검: available_macro 1h는 전체 2,950개·평가 1,088개, 1/6/12h 모두 있는 평가 시작 시점은 239개. 추가 특징의 결측 여부를 포함한 최종 수를 전부 기록한다.
- 같은 표본 안에서 모든 모델/정보 조건은 동일 목표와 시점으로 평가한다. strict와 available_macro의 평균 손실 차이는 시간대 구성도 다르므로 모델 개선으로 해석하지 않는다. available_macro의 예측을 기존 467개 시작 시점으로 제한한 비교도 별도로 제공한다.

## 정보와 알고리즘

세 정보 조건: `base`(원고 잔차·시장·거시·현지 거래활동), `full`(기존 포지셔닝 4개 추가), `history`(full에 위 네 변화량 추가). 포지셔닝 변수는 레버리지 배수나 국내 투자자의 실제 주문 흐름이 아니다.

각 알고리즘은 과거 전체/최근 90일 × 미래 수준/변화량을 동일한 내부 검증으로 선택한다.

- **선형 분위수 회귀**: alpha=0/.01/.05. 이 적응형 선형 모형이 주 비교 기준이다.
- **분위수 Gradient Boosting**: 이전 세 후보 유지: 깊이/트리 수/최소 잎 표본=(1,150,20)/(2,150,20)/(2,250,40), learning rate=.03.
- **Quantile Regression Forest(QRF)**: 150개 트리, bootstrap=True, seed 고정, (깊이/최소 잎 표본/max_features)=(5,20,1.0)/(None,20,.7)/(None,40,1.0). RF 평균 예측을 분위수라고 부르지 않는다. 각 트리의 같은 잎에 도달한 학습 관측치에 균등 질량을 주고 트리 간 평균한 조건부 가중 CDF의 10% 분위수를 계산한다. 이는 Meinshausen (2006) 식 (4)~(6)의 전체 학습 관측치 가중 방식이다.

모형/정보/정의마다 후보 12개. 내부 검증은 외부 월 직전 한 달이고, 내부 잔차 분해도 내부 학습 종료 이전에서 재추정한다. 입력/목표 표준화는 학습 자료만 사용한다. target_time < cutoff 조건으로 학습 목표가 검증/평가 구간에 걸치지 않게 한다.

## 온라인 보정

2025-11월을 실제 시간순 예측의 보정 준비 구간으로 추가한다. 이때 후보 선택은 10월까지의 정보만 쓴다. 주 평가는 이전과 동일한 2025-12~2026-03이다.

각 예측 시각 t에서 이미 목표값이 알려진(`target_time < t`) 같은 모델/정보/정의의 과거 원예측 오차 `실제 잔차 - 원예측` 중 최근 60개(최대 90일)를 사용한다. 최소 30개이면 오차의 경험적 q10을 현재 원예측에 더한다. 선형·부스팅·QRF에 동일 규칙을 적용한다. 보정 전후 모두 보고한다. 분포 이동·의존성이 있는 이 표본에서 교환가능성 기반 유한표본 보장이나 완전한 조건부 보정을 주장하지 않는다. ACI/PID를 그대로 구현한 것이라고 부르지 않는다.

이는 시간에 따라 예측오차를 적응적으로 처리하는 conformal 문헌에서 동기를 얻은 **단순 과거 오차 분위수 보정**이다. 보정 자체의 개선을 ML이나 포지셔닝의 기여로 바꿔 말하지 않는다.

## 비교와 판단

- 주 목표는 여전히 원고 회귀 잔차의 미래 q10이다. 직접적인 김프 ML 분해나 기존 main의 호가 변형 프로젝트로 바꾸지 않는다.
- 주 결과는 각 표본의 EQ·1h, 보정 전후에서 ML 대 동일 정보의 적응형 선형, full 대 base, history 대 full/base다. 다른 정의는 강건성 점검이다.
- 후보 선택에 외부 손실을 사용하지 않는다. raw/보정/정보/정의별 모든 표와 월별 결과를 공개한다. 유리한 한 조합만 골라 최초 가설 성공으로 부르지 않는다.
- pinball loss, 하회 빈도, 월별 안정성, 날짜 이동블록 불확실성을 평가한다. CI는 고정된 과거 순차 예측의 진단이며 전체 적응 경로·모형선택·분해를 재학습한 추론이 아니다. 이미 결과를 본 기간이므로 탐색적이다.
- 주 비교는 available_macro/EQ/1h/보정 후에서 (부스팅·QRF)×{history 대 동일 정보 선형, history 대 base, history 대 full} 여섯 개다. 해당 탐색적 p값의 Holm 보정도 기록한다.
- 공통 시작 시점에서 실제 1/6/12h 잔차와 가격별 조정을 계산한다. 이는 회복 시간 전체의 생존모형이나 인과 식별을 뜻하지 않는다. 장기시계 예측 모델을 이번 후속 실험에서 새로 평가했다고 주장하지 않는다.
