# 2단계 결과의 계산·설계·해석 감사

**저장 결과를 별도 계산 구현으로 대조한 범위에서는 손실·보정·선택·주 검정의 수치 오류를 발견하지 못했다. 그러나 기존 1·2단계만으로 ML 개선의 출처를 분리해 설명하기에는 실험 설계가 충분하지 않다. 3단계 위험 경보로 곧바로 넘어가기보다, 잔차 동학의 비선형성 및 추가 시장 상태 정보의 역할을 나누는 비교를 먼저 보완할 필요가 있다.**

사용자는 비유의 결과를 그대로 받아들이기 전에 잘못된 해석·코딩·실행·설계 가능성을 점검하라고 요청했다. 이번 작업은 그에 대한 사후 감사다. 새로운 예측 모델의 성능 탐색이나 보지 않은 표본 검증이 아니다. 기존 잠금·코드·예측·결과는 변경하지 않았다.

## 1. 앞선 테스트가 보장하지 않는 것

동일한 학습 코드로 예측을 재현하면 실행의 일관성은 확인할 수 있다. 하지만 그 코드가 같은 실수를 반복하거나, 연구 질문에 충분하지 않은 설계를 그대로 실행할 가능성까지 배제하지는 못한다. '테스트 통과'를 '설계와 경제적 해석까지 모두 맞다'는 뜻으로 설명하면 과도하다.

이번에는 예측 실험의 손실·보정·선택·부트스트랩 함수를 import하지 않는 [audit.py](audit.py)를 작성했다. 기존 CSV/JSON을 읽어 다른 계산 경로로 대조하고 입력 해시가 그대로인지 검사했다. 오류를 발견하지 못한 범위와 남은 설계 문제를 구분한다.

## 3. 확인한 설계·해석의 보완점

### A. 한 그룹씩 제거한 증분은 전체 개선의 출처와 다르다

2단계는 다른 모든 입력이 있는 상태에서 특정 직접 변수군이 **추가로** 도움이 되는지를 물었다. 정보가 다른 변수와 중복되면 하나를 빼도 성능이 유지될 수 있다. 따라서 세 그룹 각각이 비유의하다고 해서 시장 상태 정보 전체가 무용하거나 잔차 자체의 비선형성만 중요하다고 결론 내릴 수 없다.

이를 확인하는 단순 반례도 코드에 포함했다. A=B=Y인 구성 자료에서는 A 또는 B 하나를 빼도 q10 예측손실이 0이지만 둘 다 빼면 0.09009가 된다. 이는 논리적 반례이며 **현재 스테이블코인 자료에서 실제 중복성이 원인이라는 실증 증거는 아니다.**

현재 세 그룹은 포지셔닝과 달력 입력을 남겼다. 잔차 계산에도 환율·공통요인이 반영된다. 그러므로 이번 그룹 제거 효과를 더해 10.65% 개선을 배분하거나 '개선 원인 분석이 끝났다'고 할 수 없다. 원래 변수군 제거 실험은 좁은 질문에는 타당하지만, 넓은 연구 질문을 완결하지 않는다.

### B. 선택 지표와 최종 평가 지표가 다르다

`step2_run.py`의 `inner_job`은 보정 전 예측 `pred`의 손실로 후보를 비교한다. 최종 주 검정은 과거 오차 보정 후 `pred_calibrated`의 손실이다. 이전 전체 입력 절차도 같은 규칙을 사용했다. 이는 잠근 설계대로 실행된 것이므로 코딩 오류나 외부 점수 누출을 발견한 것은 아니다.

하지만 **최종적으로 사용하는 '모델+보정' 절차를 가장 잘 선택하려는 목적에는 정합성이 부족하다.** 원예측 손실 최솟값이 보정 후 손실 최솟값을 보장하지 않는다. 미래 보정 효과를 보고 후보를 바꾸라는 뜻이 아니다. 다음 보완에서는 후보별로 과거 내부 시점에서 이용 가능한 오차만 사용해 보정까지 순차 실행하고, 최종 평가와 같은 손실 기준으로 선택해야 한다. 충분한 과거 예측오차가 없는 초기 시점의 처리와 평가 시점 공통화도 사전에 고정해야 한다.

이 정합성을 보완하면 성능이나 변수 기여가 반드시 개선된다고 예측할 근거는 없다. 기존 비유의 결과의 원인이 이 차이라고 확정할 수도 없다.

### C. 준비 기간의 모델 선택도 보정 후 차이에 포함된다

국내 거래량 제외의 재선택 절차와 설정 유지 절차는 평가 기간의 원예측이 정확히 같았다. 그러나 11월 준비 기간 모델이 달라 과거 오차가 달랐고, 12월 1일 03:00~12월 4일 07:00 UTC의 **47개 평가 시점**에서 보정 예측 차이가 남았다. 1~3월에는 보정 예측도 같았다.

이것이 거래량 제외 시 손실 증가율 +0.3093%와 +0.0339%의 차이를 설명한다. 시간순 보정 규칙이 정상적으로 작동한 결과이며 미래 정보를 쓴 것은 아니다. 다만 그 차이를 거래량의 독립적인 경제적 기여로 해석할 수 없다. 현재 수치는 선택·준비 기간·보정까지 포함한 전체 절차의 결과다.

원본: [준비 기간 효과 대조](results/volume_warmup_carryover.csv). 다음 설계에서도 초기 오차를 어떻게 준비하고 모델 변경 후 어떻게 갱신하는지 명시해야 한다. 결과를 좋게 만들기 위해 준비 기간을 사후 삭제하지 않는다.

### D. 1단계의 단순 모형과 전체 입력 ML은 두 가지가 동시에 달랐다

1단계의 단순 잔차 동학 모형은 제한된 입력을 사용했고, ML은 전체 입력을 사용했다. 따라서 그 차이만으로 알고리즘의 비선형성과 추가 정보의 역할을 분리할 수 없다. 기존 전체 입력 선형 대비 개선은 같은 정보 조건의 비교이지만, 잔차 동학에 한정된 ML 비교가 아직 없다.

## 4. 권고하는 다음 순서

**3단계에 앞서 2단계의 설명력 부족을 보완하는 비교를 먼저 설계한다.** 아래는 다음 실험의 구조 제안이며 아직 실행하거나 새 잠금으로 고정하지 않았다.

| 입력 조건 | 선형 분위수 예측 | 정해 둔 비선형 ML 예측 |
|---|---|---|
| 잔차 동학: 현재 잔차·직전 변화 | 기준선 | 동일 입력에서 비선형성의 추가 예측력 |
| 잔차 동학 + 전체 시장 상태 정보 | 정보 추가에 따른 선형 예측력 | 비선형성 및 추가 정보의 결합 |

공통 시각·요일 통제를 사용할 경우 네 조건에 동일하게 적용하고 '잔차만'이라는 명칭에도 그 통제를 명시한다. 추가 정보에 달력 입력을 섞어 놓고 시장 정보의 효과라고 부르지 않는다. 비교모형의 계열·설정 후보와 학습창을 유한하게 고정하고, 문턱 기준선도 유지해 강한 비선형 대안에 대한 비교를 빠뜨리지 않는다.

- 같은 입력에서 선형 대 ML: 비선형 표현/학습 절차가 추가 도움이 되는가?
- 같은 학습 계열에서 제한 입력 대 전체 입력: 추가 시장 상태 정보 묶음이 도움이 되는가?
- 두 차이를 함께 보면 잔차 자체의 동학과 추가 정보의 역할을 더 직접적으로 나눌 수 있다. 인과효과 분리 실험은 아니다.

내부 모델 선택도 실제 사용되는 보정 포함 손실에 맞추고, 모든 계산은 과거 자료에서만 수행한다. 기존 결과는 보존하며 새 비교는 기존 기간에 대한 **탐색적 설계 보완**으로 명시한다. 기존 10.65%와 달라진 절차의 개선율을 그대로 이어 붙이지 않는다. 긍정적 결과가 나올 때까지 무한히 수정하는 규칙을 두지 않는다.

이 비교를 확인한 뒤 위험 경보로서의 가치(3단계)를 평가하는 순서가 적절하다. 3단계가 독립적으로 가능한 예측 활용 평가이긴 하지만, 그것만으로 2단계의 정보 출처 문제를 해결했다고 할 수는 없다.

## 5. 참고와 실행

입력 전체와 일부를 제외한 예측력을 구분하는 논의는 [Williamson et al., JASA 2023](https://arxiv.org/abs/2004.03683), 모델 선택과 평가를 구분하는 논의는 [Cawley & Talbot, JMLR 2010](https://www.jmlr.org/papers/v11/cawley10a.html)를 참고했다. 본 감사의 간단한 반례와 유한 후보 비교를 그 논문들의 효율적 추론 절차 전체를 구현한 것으로 부르지 않는다.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  python3 experiments/residual_step2_audit/audit.py
```

이미 저장된 감사 출력은 덮어쓰지 않는다. 이 코드는 완료 표식을 배타적으로 생성하므로 동일 폴더 반복 실행은 거부한다. 이전 예측 파일·선택·설계 및 이번 감사 소스의 SHA256은 [STARTED.json](results/STARTED.json)에 기록했다. 새 예측 실험의 사전등록이 아니라 사후 감사 기록이다.
