# 결과 개봉 전 자료 대조 범위 수정

고정 실행기 `92f68b5`의 준비 단계가 기존 target 파일과의 대조에서 중단됐다. 새 문맥은 최종 평가 509개 시점인데, 기존 `targets.csv.gz`는 내부 선택용 월까지 포함한 정의별1,157행이다. 기존 파일의 평가기간 필터가 누락되어 509/1,157행을 비교했다. 평가 표본 자체, 예측, 분해, 모델, 경보 문턱, 손실, 검정은 바뀌지 않는다.

원래 잠근 코드를 수정하지 않고 `dv_prepare_v2.py`에서 기존 target 파일을 읽을 때만 `origin >= 2025-12-01`로 제한한다. 509개 평가 시점은 기존 설계대로다. 원본 준비 스크립트는 그대로 유지한다. 첫 실패는 결과 파일 쓰기·점수 계산 전에 발생했다. 이 보완과 해시를 Git에 먼저 기록한 뒤 다시 실행한다.
