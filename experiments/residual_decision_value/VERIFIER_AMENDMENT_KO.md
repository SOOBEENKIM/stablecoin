# 결과 개봉 전 검증기의 분위수 경계 재현

원래 검증기는 상태 경계를 `percentile([100/3,200/3])`로 다시 계산했다. 실행기의 `quantile([1/3,2/3])`와 백분율 변환 과정의 부동소수점 차이(최대 약2.2e-15bp)가 생겼다. 경계에 정확히 걸친 학습 관측치 1~2개의 상태가 바뀌면서 상태 경험분위수의 독립 대조가 중단됐다.

봉인한 경계·예측·경보·평가 표본은 수정하지 않는다. 새 검증기는 정렬한 값에서 **확률1/3,2/3와 (n−1)p 보간 위치를 직접 계산**하고, 보간의 양 끝 선택까지 같은 수치 규칙으로 재현한다. 표본 선택이나 통계적 허용오차를 완화하는 수정이 아니다. 24개 월/정의의 경계가 비트 단위로 일치하는지 사전 점검한 뒤, 48개 월/기준선 및 보정·가격 항등식 검증을 다시 수행한다. 성능 수치는 아직 개봉하지 않았다. 원래 검증기는 잠긴 상태로 보존한다.
