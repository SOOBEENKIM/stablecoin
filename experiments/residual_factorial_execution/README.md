# 회귀 잔차의 교차 예측 비교 실행

[고정 설계](../residual_factorial_design/PROTOCOL_KO.md)를 실제 실행하는 폴더다. [실행 명세](EXECUTION_KO.md)에 적합·검증·봉인·개봉 순서와 재현 명령을 기록한다. 기존 설계와 과거 실험 결과는 보존한다.

**전체 실행·검증·평가 완료:** 주 EQ에서 전체 입력 ML 선택의 선형 대비 손실 개선은 **3.85%**였다. 고정한6개 주 비교는 모두 주 판단 기준을 충족하지 못했으며, 시장 정보/포지셔닝 증분도 뚜렷하지 않았다. 이전 대비 ML의 보정 후 손실은 비슷했지만 새 선택·보정 규칙에서 선형 손실이 더 낮아져 이전10.65%보다 격차가 줄었다. [결과와 해석](RESULTS_KO.md), [주 비교](results/primary_tests.csv), [계열별 전체 표](results/metrics.csv)를 확인할 수 있다.

실행 전18개 검증, 실제 적합7,488회, 후보별 보정1,260계열·선택288개 독립 대조,1월84개 모형 및 제외 입력 교란56개 추가 재적합을 완료했다. 재적합/보정 차이는0bp이며 기존 평가 시점·정답과도 일치한다. [실행 잠금](LOCK.json) → [예측 봉인](results/PREDICTIONS_SEALED.json) → [검증](results/VERIFICATION.json) → [개봉](results/SCORES_OPENED.json) 순서를 지켰다.

- `core.py`: 고정 후보와 변수, 실제 월별 자료·목표, 모형 적합 연결.
- `factorial_run.py`: 모든 후보 적합, 후보별 보정, 과거3개월 선택, 예측 봉인.
- `verify.py`: 독립 보정/손실/선택/블록 산술 대조, 원자료 시각 확인,1월 실제 재적합.
- `evaluate.py`, `factorial_stats.py`: 주6개 비교와 고정 보조 표, 월별·seed별·보정 전후 분석.
- `execution_guard.py`: 기존 설계 보존, 소스/입력/환경 잠금, commit/push 확인.
- `test_execution.py`: 성능 선택과 무관한 실행 동작 검증.

`render_report.py`는 평가 완료 후 추가한 표·그림·설명 생성기이며 잠긴 예측 실행이나 모델 선택을 수정하지 않는다. 같은 과거 기간의 재평가이고 독립된 새 기간의 검증은 아니다. 후속 위험 경보와1/6/12시간 가격 경로 실험은 이번 실행에 포함하지 않는다.
