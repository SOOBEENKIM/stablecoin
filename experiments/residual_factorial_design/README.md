# 잔차 동학·추가 정보·비선형 예측의 교차 비교 설계

**설계와 자료 가용성 점검 단계다. 새 예측 성능 실험은 실행하지 않았다.** 기존의 회귀 분해와 연구 방향을 유지하고, 동일 입력에서 선형/ML을 비교하는 실험을 보완한다.

- [구체적 설계와 판정 범위](PROTOCOL_KO.md)
- [고정된 후보·변수·기간·6개 주 비교](design.json)
- [선택/보정 규칙](mechanics.py), [합성 검증](test_mechanics.py)
- [자료 점검 코드](preflight.py), [가용성 기록](preflight/PREFLIGHT.json), [월별 표본](preflight/monthly_availability.csv)

3개 입력 조건 R(잔차·달력), B(+시장 정보), F(+포지셔닝)에 선형/QRF/분위수 부스팅/문턱형을 각각 적용한다. 계열별 성적과 과거에서 QRF/부스팅을 선택하는 절차의 성적을 모두 내도록 정했다. 후보별 시간순 보정을 한 뒤 같은 보정 후 손실로 후보를 선택한다.

입력당60개 후보를 고정했다. 개별 정보군 제거만으로 개선의 출처를 추정하지 않고, 시장 정보의 결합 가치와 포지셔닝의 증분을 나눈다. 전체 입력에서 선택한 같은 후보 설정을 제한 입력에 적용하는 보조 비교도 의무화했다. 기존10.65%는 보존하며 새 실험의 전체 입력 칸에 재사용하지 않는다.

검증 명령(저장소 루트):

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  python3 -m unittest discover -s experiments/residual_factorial_design -p 'test_*.py' -v
```

합성 테스트는8개이며 정보 중첩/공통 달력, 고정 후보군, 손실 방향/표현 불변, 보정 정답 시각과 경험 분위수, 후보 오차 혼합 거부, 오차 만료, 보정 후 기준 선택, 미래/경계/누락 시점 거부를 점검한다. 예측 모델의 실제 성능이나 전체 경제적 타당성을 확인한 테스트가 아니다.

`preflight.py`는 기존 월별 회귀 잔차를 계산해 시점과 문턱 학습 표본을 확인한다. 예측기는 적합하지 않으며 저장된 과거 예측 파일에서도 시점 식별 열만 읽는다. 실제 시점에 가상의0오차를 배치해 보정 이력이 충분한지 검사한다. 기존 점검 출력은 덮어쓰지 않는다.

실제 점검에서 EQ/CAP/PCA 각1,088개, strict467개의 평가 시점이 이전 기록과 정확히 일치했다. 9월 이후 모든 시점에서 사용할 수 있는 과거 보정 오차는60개였고, 가장 작은 문턱 학습 구간도56개로 고정 기준40개를 넘었다. 이는 시간·표본 측면의 실행 가능성 확인이며 새 모델의 적합 성공이나 예측력 개선을 보장하지 않는다.

**DESIGN_LOCK.json은 이 설계·보조 코드·자료 점검·원자료/기존 의존 소스의 해시 기록이다.** 후속 예측 실행기는 아직 구현하지 않았다. 구현·검증을 마친 뒤 별도 실행 잠금과 commit/push가 필요하다. 이번 기록은 독립 표본에 대한 사전등록이 아니다.
