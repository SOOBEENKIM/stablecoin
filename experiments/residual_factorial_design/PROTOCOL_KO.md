# 잔차 예측 개선의 출처를 구분하는 교차 실험 설계

작성일: 2026-09-25. 기존 결과를 확인한 뒤 작성한 **후속 설계**다. 추가 수집 없이 기존 자료를 사용한다. 이번 변경에서는 설계·선택/보정 규칙·자료 가용성만 점검하며 새 예측 성능 실험을 실행하지 않는다. 실제 예측 실행기는 후속 작업에서 이 명세에 맞춰 구현·검증·잠금해야 한다.

## 1. 연구 질문과 이번 보완의 이유

원래 방향은 유지한다. 시장 공통요인과 글로벌 괴리를 회귀로 고려한 한국 USDT 잔차에서, 이후 하단 꼬리의 움직임을 현재 상태로 예측할 수 있는지 연구한다. **ML은 잔차를 만드는 단계가 아니라 잔차의 미래 조건부 하위 분위수를 예측하는 단계에 사용한다.**

앞선 선형 대비 약 10.65% 손실 개선은 당시 전체 절차의 결과로 보존한다. 하지만 단순 모형보다 입력도 많았던 비교, 정보군 하나씩만 제거한 비교로는 개선의 출처를 충분히 설명할 수 없었다. 내부 선택은 보정 전 손실, 주 평가는 보정 후 손실이었다. 이번에는 다음 질문을 분리한다.

1. **같은 입력에서** 선형보다 QRF/분위수 부스팅을 이용한 예측 절차가 유용한가?
2. **같은 후보군과 선택 규칙에서** 추가 시장 정보 묶음이 유용한가?
3. 시장 정보를 이미 준 상태에서도 **롱숏·펀딩·OI 정보가 추가로** 유용한가?
4. 그 개선은 단순한 비선형 대안인 **문턱형 분위수 모형**으로도 설명되는가?

비선형 학습 절차와 선형 학습 절차의 비교다. 성능 차이만으로 경제적 관계의 구조적 비선형성이나 포지셔닝의 인과효과를 증명하지 않는다. 모델의 정규화·국소 가중·선택도 절차 차이에 포함된다.

## 2. 3개 입력 × 4개 모형 계열

모든 칸은 같은 잔차 목표·학습/평가 시점·과거 선택 기간을 사용한다. 각 입력 조건에서 각각 다시 학습하고 설정을 선택한다.

| 입력 조건 | 선형 분위수 | QRF | 분위수 부스팅 | 문턱형 분위수 |
|---|---|---|---|---|
| R: 현재 잔차·직전 변화 + 공통 달력 통제 | 실행 | 실행 | 실행 | 실행 |
| B: R + BTC 시장·국내 거래량·환율/거시 정보 | 실행 | 실행 | 실행 | 실행 |
| F: B + 롱숏·펀딩·OI 수준/변화 | 실행 | 실행 | 실행 | 실행 |

네 계열 결과를 모두 공개한다. 별도로 QRF와 부스팅의 합집합에서 과거 점수로 선택하는 **`ml_selected`**를 둔다. 이는 다섯 번째 알고리즘이나 앙상블이 아니며 추가 적합 없이 후보 예측을 선택하는 절차다. 선형·문턱형을 ML 선택 풀에 섞지 않는다. QRF 또는 부스팅 중 외부 성적이 좋은 계열을 사후 주 모형으로 바꾸지 않는다.

입력은 [design.json](design.json)에 열 이름까지 고정했다.

- **R**: `e_now`, 실제 1시간 전과의 차이 `e_change1`, 한국 시각의 `hour_sin/hour_cos/weekend`. 잔차의 모든 과거 이력을 포함한다는 뜻은 아니다.
- **B에 추가**: BTC 1시간 수익률·직전24시간 변동성·하방변동, 국내 USDT 거래량 surprise, 환율·DXY·VIX 변화율. `available_macro`에서는 VIX 최근 관측 수준과 VIX/DXY 관측 경과시간도 추가한다.
- **F에 추가**: 계정 롱숏 비율 로그, 펀딩비, OI 1시간 변화·surprise, 계정 비율 1/24시간 변화, 펀딩 8시간 변화, OI 24시간 변화. 개별 계정의 레버리지 배수나 실제 청산 금액은 아니다.

주 조건의 입력 수는 **R=5, B=15, F=23**이다. strict 조건은 **5, 12, 20**이다. 달력 통제를 모든 칸·조건에 똑같이 주기 위해 기존 strict 실험에 없던 달력 3개를 명시적으로 추가한다. 이 변경은 미리 고정하며 과거 strict 성적과 동일 모형이라고 부르지 않는다. R에도 분해 시 반영된 시장 정보가 내재하므로 R과 B의 비교는 **직접 예측 입력의 증분**이다.

**설정 변화에 대한 필수 보조 비교:** 각 월 F의 `ml_selected`가 과거 자료로 선택한 후보 ID를 R/B/F 모두에 적용한다. 같은 계열·학습창·목표 표현·하이퍼파라미터로 각각 재학습한 예측과 각자 보정을 사용한다. 이미 생성한 후보 예측을 재사용한다. 주 정보 비교는 입력별로 최적화된 절차의 차이이고, 이 보조 비교는 선택 설정을 맞춘 차이다. 계수·트리까지 같게 두는 실험은 아니다. 두 결과가 엇갈리면 설정 선택에 민감한 효과로 보고한다.

## 3. 바꾸지 않는 분해·목표·표본

기존 `data.py`의 수정된 환산·시각 처리와 순차 회귀를 유지한다. 월 시작 M 직전 자료에서 USDT 프리미엄을 공통 프리미엄에 회귀하고, 그 잔차를 글로벌 괴리에 회귀한다. 해당 월의 두 시점 모두 **같은 월초 계수**로 잔차를 계산한다. PCA 표준화·적재량도 과거에서만 추정한다. 회귀 분해 잔차가 모든 공통 경제 영향을 완전히 제거했다는 뜻은 아니다.

- **예측 목표**: `Q_0.10(e[t+1h] | information_at_t)`, 단위 bp. 정답은 실제 시계상 1시간 뒤이고 다음 관측행으로 대체하지 않는다.
- 이는 **미래 잔차 수준의 하위 10% 경계**이지, USDT 달러 디페깅 확률·국내 가격의 하락 확률·수익률이 아니다. `q_pred − e_now`로 잔차 변화의 하위 분위수도 표현한다. 현재 잔차가 알려져 있으므로 수준/변화 표현의 pinball 손실은 동일하지만, 표현별 학습 제약이 달라 후보로 비교한다.
- **주 조건**: `available_macro/EQ`, 평가 2025-12-01~2026-03-19, 기존 **1,088개 시점**. 모든 칸에서 공통 complete-case 마스크를 사용한다. R에서 불필요해진 변수의 결측을 허용해 표본을 늘리지 않는다.
- **보조 조건**: CAP/PCA 각 1,088개, strict/EQ 467개. CAP은 기존 고정 공급량×가격 가중 대용치이고 PCA는 기존 첫 주성분이다. 보조 결과가 좋아도 EQ를 대체하지 않는다.
- 원자료의 시간대·공개 지연 가정, 새 환율 관측 필요 조건, DXY/VIX 최대96시간 과거 관측 사용 규칙은 기존대로 유지한다. strict는 기존의 더 엄격한 거시 관측 조건이다. 암호화폐 24시간 전체 시장을 빠짐없이 평가한 표본이라고 주장하지 않는다.
- 같은 월/조건에서 잔차·정답은 모든 모델·입력에 동일하다. 다른 잔차 정의나 strict와의 차이는 여러 조건이 함께 달라지므로 차이의 원인을 하나로 특정하지 않는다.

## 4. 모델 후보를 유한하게 고정

각 계열에서 학습창 `all / 최근90일`과 목표 표현 `level / change`를 동일하게 허용한다. 월별 학습 자료는 **목표 시각이 월 시작보다 엄격하게 이전**인 행만 사용한다. 표준화·분위수 경계·트리는 해당 학습 자료에서만 적합한다.

| 계열 | 계열별 설정 | 후보 수/입력 |
|---|---|---:|
| 선형 분위수 회귀 | 정규화 alpha 0, .01, .05 | 12 |
| QRF | 트리150개; (깊이5, 잎20, 변수비율1), (깊이제한없음, 잎20, .7), (깊이제한없음, 잎40, 1) | 12 |
| 분위수 부스팅 | (깊이1, 트리150, 잎20), (깊이2, 트리150, 잎20), (깊이2, 트리250, 잎40); 학습률.03, subsample1 | 12 |
| 문턱형 분위수 회귀 | 학습 잔차 경계20/80% 또는35/65%; alpha 0, .002, .01 | 24 |

문턱형은 잔차 3개 구간별 절편·기울기를 허용하고 학습 구간당 최소40개가 필요하다. 기존 김치프리미엄 문턱 평균회귀 논문을 그대로 복제한 구조모형은 아니다. QRF는 잎에 속한 학습 정답의 가중 경험분포에서 분위수를 구하며 트리 평균 예측들의 분위수를 쓰지 않는다.

입력당60개, 3입력, 8개월(8월~3월), 주 조건4seed와 보조3조건 각1seed를 모두 실행하면 캐시 전 적합 상한은 **10,080회**다. 새 구조·변수·탐색 범위를 외부 결과를 본 뒤 추가하지 않는다. 이번 질문을 위한 유한한 비교이며 과거 상호작용/스플라인 실험을 삭제하거나 열등함을 재확정하는 작업은 아니다. ML 합집합24개와 선형12개의 탐색 크기는 다르므로 개별 QRF/부스팅12개 결과도 필수 공개한다.

## 5. 후보별 시간순 보정과 모델 선택을 일치시킨다

**중요한 변경:** 과거에 선택됐던 서로 다른 후보의 오차를 이어 붙여 보정하지 않는다. 모든 고정 후보 ID에 대해 각자의 과거 월별 표본 외 예측을 생성·보존하고, 그 후보의 오차만으로 보정한다. 월마다 학습 계수는 갱신하지만 후보 ID의 계열·설정·창·표현은 동일하다. 과거 예측이나 과거 정답 잔차를 나중 월의 분해 계수로 다시 계산하지 않는다.

1. **8월부터 후보별 예측 기록 생성**: 각 월 이전 자료로 분해·예측 모형을 학습하고 그 월을 예측한다. 8월은 보정 준비용이며 외부 성적에 넣지 않는다.
2. **각 시점 t의 보정**: 같은 조건/입력/후보/seed에서 정답 시각이 `t보다 엄격하게 이전`인 원예측 오차 `e_future − q_raw`를 사용한다. 최대90일 안의 최근60개, 최소30개 오차의 경험적 q10(`inverted_cdf`)을 원예측에 더한다. 오차30개 미만인 준비 구간만 보정0을 사용한다. 9월 이후 선택·평가 시점에서 부족하면 중단하며 그 시점을 사후 삭제하지 않는다. 이는 경험적 오차 보정이며 분포무관한 정확한10% 보장이나 독립성 가정을 충족한 conformal 검증으로 부르지 않는다.
3. **월 M 직전 선택**: 직전3개월의 후보별 **보정 후** pinball 손실 합/관측 수로 선택한다. 내부 검증 월의 다음 달 경계에 걸리는 정답과 M 이후 정답은 제외한다. 모델마다 내부 시점을 달리하지 않는다. 정확히 동점이면 후보 ID가 작은 것을 사용한다.
4. **월 M 평가**: 선택된 후보의 M월 예측을 사용한다. 그 달 안에서는 새로 알려진 과거 정답만으로 보정을 갱신하며 모델·설정은 월초 선택을 유지한다. 다음 월에는 이전 월에서 이미 알려진 정답을 학습/선택에 사용할 수 있다. 이는 사전에 고정한 순차 평가 규칙이다.

| 평가 월 | 설정 선택에 사용하는 세 달 | 예측 모형 학습의 마지막 경계 |
|---|---|---|
| 2025년12월 | 9·10·11월 | 12월1일 이전 정답 |
| 2026년1월 | 10·11·12월 | 1월1일 이전 정답 |
| 2026년2월 | 11·12·1월 | 2월1일 이전 정답 |
| 2026년3월 | 12·1·2월 | 3월1일 이전 정답 |

각 계열은 자기 후보군 안에서 선택하고 `ml_selected`는 QRF+부스팅 안에서 선택한다. 선택은 기존 첫seed20260925로 고정하고, 주 조건은 같은 후보 ID를 네seed20260925~28에서 평가한다. 다른seed의 보정도 해당seed의 후보별 오차를 사용한다. 시점별 네seed **손실 평균**이 주 점수다. 예측을 평균하는 앙상블을 만들거나 표본 수를4배로 세지 않는다.

원예측 결과도 함께 공개하되 **보정 후 기준으로 이미 선택한 동일 후보의 원예측**이다. 원예측에서 유리한 모델을 별도로 골라 주장을 바꾸지 않는다. 원예측과 보정 후 비교는 보정 의존성 진단이며 원예측 절차 전체에 최적화한 별도 대회는 아니다.

## 6. 주 비교 6개와 불확실성

주 평가 지표는 q10 pinball 손실이다. `error = 실제 미래 잔차 − 예측 분위수`에 대해 `max(.1×error, −.9×error)`를 평균한다. 잔차 RMSE나 학습 적합도로 모형을 선발하지 않는다.

| 고정 비교 | 답하려는 질문 |
|---|---|
| R의 ML 선택 vs R의 선형 | 제한된 잔차 입력에서 비선형 학습 절차가 유용한가? |
| F의 ML 선택 vs F의 선형 | 전체 입력을 같게 줘도 ML 절차가 유용한가? |
| B의 ML 선택 vs R의 ML 선택 | 직접 시장 정보 묶음을 추가할 가치가 있는가? |
| F의 ML 선택 vs B의 ML 선택 | 포지셔닝이 시장 정보 위에 추가 정보를 주는가? |
| F의 ML 선택 vs R의 ML 선택 | 추가 정보 전체의 결합 가치가 있는가? |
| F의 ML 선택 vs F의 문턱형 | 단순 문턱 비선형 대안보다 더 유용한가? |

**개선율 = `100 × (1 − L_candidate / L_reference)`**. 양수면 오른쪽 기준보다 비교 대상의 손실이 작다. 절대 손실 차이(bp)도 함께 낸다. 개선율은 수익률이나 하락 확률 감소율이 아니다. 정보군의 효과는 일반적으로 가산적이지 않으므로 이 개선율들을 합산하거나 기존10.65%를 배분하지 않는다.

- 주 조건/보정 후의6개 비교에만 하나의 Holm 보정 가족을 적용한다. 사후에 불리한 비교를 빼지 않는다.
- 같은 시점의 손실을 짝지어 월별 층화 **5일 달력 원형 블록**을1,999회 재표집한다. 각 월 첫~마지막 평가일 사이의 빈 날은 일별 합/개수0으로 유지한다. 월별 달력 길이를 채우고 마지막 블록은 잘라 합산한다. 난수는20260925+블록일수다.
- 95% 개선율 구간은 백분위 구간, 양측 p는 절대 손실차이의 중심화 부트스트랩 및 +1 보정을 사용한다. 구간은 개별 구간이며 동시 신뢰구간으로 부르지 않는다. Holm p<.05와 양의 개선/구간 하한을 함께 만족할 때 그 비교가 이 설계의 주 기준을 지지한다고 보고한다.
- 1/10일 블록, 원예측, 월별·seed별, 개별 QRF·부스팅, 같은 설정 비교, CAP/PCA/strict를 **모두** 공개한다. 같은 예측을 고정한 블록 추론은 전체 모델 재선택·과거 인간의 탐색까지 보정하지 않는다. 이전에 본 자료이므로 유의한 결과도 독립적 확인으로 격상하지 않는다.
- `실제 < 예측 분위수`의 하회율, 보정 크기, 후보 선택 기록도 낸다. 하회율10% 근접만으로 좋은 위험 예측이라고 판정하지 않는다. 월별로 방향이 갈리거나 보정·seed·조건에 민감하면 그 범위를 명시한다.
- 비유의 결과는 기여가0이거나 두 모델이 동등하다는 증명이 아니다. 사전에 경제적으로 정당화한 동등성 허용폭이 없으므로 동등성 검정을 사후 도입하지 않는다.

## 7. 결과에 따라 주장할 수 있는 범위를 미리 정한다

| 결과 패턴 | 허용되는 해석 |
|---|---|
| R의 ML이 선형보다 좋고 추가 정보 효과는 불명확 | 정해 둔 잔차·달력 입력의 비선형 예측 절차가 유용할 수 있음. 시장 정보나 포지셔닝이 개선 원인이라는 주장은 보류 |
| B가 R보다 좋고 F가 B보다 좋은지는 불명확 | 직접 시장 상태 정보는 유용하나 포지셔닝의 독립적인 증분은 확인하지 못함 |
| F가 B보다 좋고 같은 설정/민감도 분석도 일관됨 | 관측한 포지셔닝 지표 묶음의 추가 **예측 정보**를 지지. 실제 레버리지/청산의 인과적 경로 입증은 아님 |
| ML과 문턱형 차이가 불명확 | 문턱형을 넘어서는 ML의 우위는 주장하지 않음. 비선형/상태 의존 예측이라는 범위에서 비교 결과 제시 |
| 원예측에서는 불명확하고 보정 후에만 개선 | 모델+시간순 보정의 전체 절차 효과로 명명. ML 단독의 보정 전 우위라고 쓰지 않음 |
| 주 조건에서 개선되지 않거나 결과가 불안정 | 추가 모델 탐색으로 유의성을 만들지 않고 효과 크기·불확실성·실패 조건을 공개 |

이 표의 일부 조건을 충족해도 새로운 알고리즘을 발명했다는 기여는 아니다. 주어진 시장·잔차 정의에서 어떤 정보/예측 절차가 유효한지에 대한 실증 기여이며, 워크숍의 시장미시구조 기여로 설명하려면 실제 가격 조정과의 연결까지 별도로 확인해야 한다.

## 8. 구현·검증·개봉 순서

1. **이번 변경**: 명세·기계가 읽는 설정을 저장하고 합성자료로 선택/보정 규칙을 검사한다. 실제 자료에서는 가용 시점·학습 구간별 문턱 표본·보정 준비량·기존 평가 시점 일치만 확인한다. 새 예측기 적합/성능 계산은0회다.
2. **후속 실행 전**: 이 규칙의 실행기를 구현한다. 원자료부터 입력/목표 시각을 점검하고, 정보 조건별 재학습·후보별 보정·내부 선택·시드 집계·짝지은 통계를 독립적인 계산으로 검증한다. 구현·분석기·테스트·입력·환경을 별도 실행 잠금에 넣고 commit/push한다. 현재 설계 잠금만으로 미래 실행 코드까지 잠겼다고 주장하지 않는다.
3. **전체 실행**: 모든 후보·월·입력·조건의 예측을 저장하고 봉인한 다음 주 점수를 계산한다. 오류·결측 예측·해결되지 않은 적합 경고는 후보를 조용히 탈락시키지 않고 중단 사유로 기록한다. 기대한60개 후보나 공통 시점을 확보하지 못하면 점수 표를 만들지 않는다. 설계 변경이 필요하면 이유와 이전 명세를 남긴 새 버전을 만든다.
4. **개봉 전 필수 검증**: 기존 분해 목표와 표본 일치; 월초 학습/정답 경계; 삭제 입력 교란에 대한 제한 입력 모형 불변; QRF 가중치 합/경험 분위수; 후보별 보정의 미래 정답 불변; 내부 선택 전수 재계산; 주 조건1월 모든 정보×계열 선택 모형×seed 및 보조 조건 첫seed 실제 재적합; 동일 예측에 대한 독립 손실·짝지은 블록 계산. 재적합 일치는 전체 경제적 타당성의 증명이 아님도 명시한다.
5. **개봉 후**:12개 기본 칸과 ML 선택3개 칸,6개 주 비교와 모든 정해 둔 진단을 한 번에 정리한다. 좋게 나온 지표·조건·월만 골라 내지 않는다. 코드 오류를 발견하면 영향 범위·원인·수정 전후를 남기고 새 버전으로 전체 영향 비교를 재실행한다.

출력 명세: 후보별 원예측/보정 예측/실제 정답/보정 수와 최신 정답 시각; 과거3개월 선택 점수/ID; 월별 학습 종료·잔차 계수·입력 열; 주/보조/월별/seed별 손실·하회율;6개 주 효과·구간·Holm p; 같은 설정 비교; 원자료/소스/환경 해시와 시작/봉인/개봉 기록.

## 9. 기존 결과와 후속 3·4단계의 관계

기존10.65%와 1·2단계 결과는 삭제하지 않는다. 보정 기록 구성과 선택 목적함수가 달라졌으므로 **이번의 전체 입력 칸도 새 규칙으로 재실행**한다. 과거 전체 입력 성적에 새 R/B 성적을 붙여 비교하지 않는다. 새 수치가 예전보다 높거나 낮아도 연구 목표에 맞는 쪽만 채택하지 않는다.

이번 설계는3단계 이전에 필요한 비교를 보완한다. 이 결과만으로 가격 조정의 경제적 설명까지 완료하지 않는다. 후속 위험 경보·가격 경로 분석은 여기서 고정된 예측을 사용하고 예측기를 다시 튜닝하지 않는 방향으로 진행한다. 경보 사건/예산과 비교 규칙은 그 분석 전에 별도로 고정해야 하며 **이번 문서는3·4단계 실행 잠금이 아니다.**

가격 경로에서는 국내 USDT 가격·환율·글로벌 교환비율·공통 프리미엄 항의 실제1/6/12시간 변화를 구분해야 한다. 잔차 하락이 곧 국내 가격 하락은 아니며, 회계적 가격 분해나 유사 출발 상태의 비교가 인과적 메커니즘을 증명하지도 않는다. 예측 기여가 제한적이어도 후속 경로 분석을 금지하는 것이 아니라 그때 주장할 수 있는 범위를 제한한다.

## 10. 참고한 방법과 적용 범위

- Meinshausen (2006), [Quantile Regression Forests](https://www.jmlr.org/papers/v7/meinshausen06a.html): 조건부 분위수와 잎의 학습 정답 분포를 사용하는 방법의 근거. 이번 금융 자료에서 성능 개선을 보장하는 논문은 아니다.
- Cawley & Talbot (2010), [On Over-fitting in Model Selection and Subsequent Selection Bias in Performance Evaluation](https://www.jmlr.org/papers/v11/cawley10a.html): 모델 선택과 평가를 구분하는 근거. 이번 잠금도 이미 본 평가 기간을 새 독립 자료로 바꾸지는 못한다.
- Williamson et al. (JASA 2023), [A general framework for inference on algorithm-agnostic variable importance](https://arxiv.org/abs/2004.03683): 전체/제한 입력 예측력의 비교로 정보 가치를 정의하는 배경. 이번 유한 후보의 시간순 절차는 해당 논문의 oracle 중요도·효율적 점근 추론을 그대로 구현한 것이 아니다.

이 설계는 앞선 비교의 해석상 빈틈을 줄인다. **데이터 기간과 대표성, 시간대/공개 지연의 원자료 가정, 반복 탐색 이력, 예측과 인과의 차이까지 없애는 설계는 아니다.**
