# A2: 비선형 공통 요인 조정의 확대 비교

2026-09-24. A1의 고정 LightGBM 결과를 본 **뒤** 설계한 후속 탐색이다. 이 문서와 코드를 A2 실행 전에 커밋한다. 독립적인 사전등록·미사용 표본 검증이라고 부르지 않는다. A1 코드·설정·결과는 보존한다.

## 목적과 해석

`y = f(m, g) + e`에서 동시점 공통 요인에 대한 조건부 평균을 더 정확히 추정할 수 있는지 비교한다. 진짜 관계가 비선형이면 선형 잔차에 공통 요인의 설명 가능 부분이 남을 수 있다. 그러나 유한 표본의 ML은 추정 오차가 있으며, 잔차를 무조건 작게 만드는 것이 경제적 식별을 보장하지 않는다.

프리미엄 y와 m은 같은 환율·상대가격 환산을 공유한다. 경제적 해석에는 이 공통 측정 구조도 고려해야 한다. 포지셔닝·하방 변수는 A2의 분해 입력에서 제외한다. 이후 잔차의 포지셔닝 계수를 인과효과로 읽거나 A2를 DML이라고 부르지 않는다.

가격 정의, 입력 m·g 두 개, 동일가중 다섯 코인, 다섯 시간대 가정, 동시점 조건부 적합이라는 범위는 [기존 규칙](../PROTOCOL_KO.md)과 같다. 새 변수 추가 효과와 알고리즘 효과를 섞지 않는다. 실제 미래 예측인 B단계는 별도다.

## 후보를 넓히는 이유와 설정

| 모형군 | 목적 | 후보 설정 |
|---|---|---|
| 순차 OLS | 원래 두 단계 방식 | 1개 |
| 공동 OLS | 주 선형 기준 | 1개 |
| 최근 구간 공동 OLS | 관계의 시간 변화와 비선형성을 구별 | 최근 30·60·120일 |
| 2차 다항 Ridge | 곡률과 m×g 상호작용 | alpha=0.1·10·1000 |
| 선형+가법 spline Ridge | 매끄러운 비선형 보정 | knots=3·5, alpha=1·100 |
| 선형+RBF SVR | 매끄러운 비가법 보정 | C=1·10, gamma=0.1·1, epsilon=0.5bp |
| 선형+Random Forest | 분기·상호작용 보정 | 150 trees, depth=3·무제한, min_leaf=25·100 |
| 직접 LightGBM | A1과 같은 계열의 설정 민감도 | trees=100·300, leaves=7·15, min_child=30·100 |
| 선형+LightGBM | 큰 선형 관계 위의 비선형 보정 | 직접 LightGBM과 같은 8개 설정 |

총 9개 모형군, 36개 설정이다. LightGBM은 learning_rate=0.03, max_depth=3/4(각 leaves=7/15), reg_lambda=1로 둔다. 난수 seed=20260924, 단일 스레드다. SVR은 epsilon-insensitive 손실, 나머지 회귀 후보는 제곱손실 계열이다. 모든 후보는 검증 MSE로 선택한다.

다항모형은 학습자료로 표준화한 m·g의 1·2차항과 상호작용을 구성하고 다시 표준화한 뒤 Ridge를 적합한다. spline은 3차 가법 B-spline, 학습 범위의 균등 매듭, 선형 외삽을 사용한다. 상대가격 변수의 반복 값에 분위수 매듭이 겹치는 문제를 피하기 위한 설정이다. 보정형은 **해당 학습구간 안에서** 공동 OLS를 적합하고 그 학습 잔차를 비선형 모형에 적합한다. 이 보정 절차 자체는 cross-fitting 또는 DML이 아니다. 성능은 이후 검증·평가구간에서만 판정한다.

## 시간순 선택과 평가

- 외부 평가월: 2026년 1·2·3월. 각 평가월의 직전 3개 달을 내부 검증월로 사용한다. 예: 1월 평가는 10·11·12월 검증으로 설정을 고른다.
- 각 내부 검증월도 해당 월 **이전 자료만** 학습한다. 무작위 교차검증을 쓰지 않는다. 현재 목표는 동시점 y이므로 미래 정답 시계에 따른 purge는 없고 모든 학습시각은 검증시작보다 엄격히 앞선다.
- 설정 선택은 내부 3개월의 관측별 제곱오차를 합산한 MSE 최소화다. 동률이면 코드에 명시한 후보 순서를 따른다.
- 모형군마다 설정을 선택한 뒤 평가월 이전 자료로 재적합한다. 전처리·표준화·매듭도 학습자료에서만 적합한다.
- 추가로 전체 후보 중 내부 MSE가 가장 낮은 모형을 고르는 `past_selected` 절차를 평가한다. 실제 평가월 점수로 최종 승자를 고르는 것과 구별한다.
- 2·3월 학습에 앞서 관측된 평가월 자료가 들어가는 것은 미리 정한 순차 갱신이다. 이미 확인한 역사자료를 새 확증 표본이라고 부르지 않는다.
- 모든 모형은 각 시간대 가정 안에서 동일 관측치를 평가한다. 시간대 사이 최저 오차로 올바른 시간대를 결정하지 않는다. FX UTC 두 행은 A2 입력이 같아 독립 반복이 아니다.

## 결과·진단·불확실성

조건부 평균 조정의 주 지표는 RMSE, 보조는 MAE·잔차 평균·분위수·정확한 1시간 자기상관이다. A1의 MAE 중심 설명을 사후 바꿔 숨기지 않고 두 지표를 모두 보고한다.

모든 모형군의 월별·합산 점수, 모든 내부 검증 점수, 선택 설정, 학습 점수, 입력 범위 외 평가 비중, m·g의 학습 분위수 구간별 평가 잔차 평균을 저장한다. 이 진단은 잔차가 공통 요인과 무관하다는 확증 검정이 아니다.

공동 OLS 및 검증으로 선택한 최근 구간 OLS와의 RMSE·MAE 차이를 함께 보고한다. 월별로 층화한 **달력일 3일·7일 원형 블록** 재표집 2,000회로 손실 차이의 점별 95% 구간을 구한다. 관측이 없는 날도 블록 안에 보존한다. 동일 시점 손실을 함께 재표집한다. 이는 고정된 적합값에 조건부인 탐색적 구간이며 재학습·모형 선택·생성 잔차 불확실성·다중 비교를 완전히 반영하지 않는다. 유의한 발견이나 가족 전체 우위의 확증으로 쓰지 않는다.

`past_selected`를 포함해 결과를 전부 보고한다. 결과를 보고 이번 설정 목록을 늘리거나 좋은 달만 골라내지 않는다. 개선이 있으면 조건과 규모를 기록하고, 없으면 이 입력·표본에서의 한계로 기록한다. 어느 경우든 공통 요인 조정 성능만으로 포지셔닝 경로나 경제적 원인의 입증이 완성되지는 않는다.
