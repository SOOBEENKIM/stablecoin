# A5 실행 중 발견사항과 해석 제한

## 과거 평균 기준의 함정

고정 프로토콜의 probe 평가는 각 방법의 과거 out-of-sample 잔차 평균을 기준으로 삼았다. 결과 확인 중 AE의 2025년 10월 잔차가 커서 이후 과거 평균이 크게 이동한 것을 확인했다. UTC 시나리오에서 Jan–Mar AE에 대한 tree probe는 과거 평균 대비 MSE를 약 81% 줄였지만, 예측은 대부분 0 부근이었다. 이를 공통 요인의 잔여 의존성을 81% 설명했다는 식으로 해석하면 잘못이다.

`baseline_audit.py`는 학습·모델 변경 없이 잔차 0 기준 MSE(기존 잔차 RMS의 제곱)를 추가 계산한다. 이는 결과 확인 후의 **비교 기준 감사**다. 원래 과거 평균 기준 표를 그대로 보존하고 두 수치를 함께 제시한다. 0을 이긴다고 곧바로 독립성 검정 또는 구조적 공통 성분 식별이 되는 것도 아니다.

## 문헌 표기의 정정

고정 프로토콜의 Nechvátalová et al. (2025)는 **Nechvátalová (2025), 단독 저자**로 정정한다. 평가 설계에는 영향이 없는 서지 표기 정정이며 원본 프로토콜/해시는 보존한다.

## 평가 범위

- A5 예측기는 프로토콜의 고정 QR/LightGBM이다. 가능한 모든 예측 알고리즘을 배제하는 결과가 아니다.
- 원시 프리미엄 변화 예측은 거래 비용을 반영한 투자 수익이나 유동성 개선을 입증하는 검사가 아니다.
- A5 새 bootstrap은 core M2를 다룬다. A4의 full-macro 모형은 기존 점추정 민감도이며 A5의 새 1단계 재추정 구간으로 표시하지 않는다.
- 잔차 정의가 다른 모델의 raw pinball loss를 직접 순위화하지 않는다. 같은 관측된 목표에 대한 손실 비교와 자기 잔차 기준의 skill을 구분한다.
- 정규화 QR의 해가 같아 예측손실 차이가 부동소수점 반올림 수준인 경우가 있다. 1e-8bp 이하 차이는 `forecast_contrast_audit.csv`에서 numerical_tie로 표시하며 엄밀한 부등호 때문에 구간이 0 한쪽에 놓여도 개선/악화라고 세지 않는다. 원래 수치 표는 보존한다.
- PC2가 DOGE와 다른 코인의 대비를 담는다는 것은 관측된 loading/제외 실험 결과다. 호가단위, 거래 비동시성, 투자 수요 중 어느 것이 원인인지 식별한 것은 아니다.
