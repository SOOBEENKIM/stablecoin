# A4: 비선형 잠재 공통 요인과 상태 의존 요인 민감도

2026-09-24. 이미 결과를 본 역사자료에 대한 **추가 탐색**이다. 실행 전 후보·평가 규칙을 고정하고 코드와 함께 커밋한다. A1–A3 결과는 보존한다.

## 목적과 문헌 적용

고정된 EQ5 김프에 대한 회귀함수만 바꾼 A2/A3와 달리, 참조 코인 5종(BTC/ETH/XRP/SOL/DOGE)의 개별 김프에서 공통 요인을 비선형 추출한다. 한국 USDT 프리미엄의 공통 성분을 제거하고 잔차의 하방·지속성·포지셔닝 연관성을 분석하는 기존 연구 질문을 유지한다.

- Spilak·Härdle (2022 **v1**)의 오토인코더 잠재요인 분해를 참고한다. 실제 원고의 §§2.4–2.4.4, 암호화폐 포함 자료와 결과를 확인했다. https://arxiv.org/abs/2204.02757v1 . 최신 v2는 제목과 초점이 바뀌므로 v1을 명시한다. 본 실험은 수익률 대신 김프를 사용하며 포트폴리오용 양수·단위노름 제약을 복제하지 않는다. 정규화한 소규모 오토인코더로 확장한 **응용**, 원 논문의 재현은 아니다.
- Gu·Kelly·Xiu (2021), Journal of Econometrics, https://doi.org/10.1016/j.jeconom.2020.07.009 의 조건부 요인 민감도 아이디어도 비교한다. 확인 범위는 출판사 초록·서론·모형 설명과 저자 소속기관 요약이다. 원 논문은 미국 주식의 기업 특성→요인 민감도와 잠재요인을 추정한다. 여기서는 훈련 기간 PCA1을 공통 요인으로 고정하고 참조 코인 김프의 단면 분산도→USDT 민감도 관계를 작은 신경망으로 확장한다. 원 논문의 결합 추정·무차익 제약·경제적 식별을 구현했다고 주장하지 않는다.
- Seo 외 (2024)의 문턱 김프 동학은 비선형성 검토의 배경이지만, 이번 A4는 그 동적 문턱회귀를 실행하는 실험이 아니다.
- FactorVAE 2026 프리프린트는 초록만 확인했으므로 이번 구현 근거 또는 재현 대상으로 삼지 않는다.

## 분해와 대조군

`K_t = (5개 참조 코인 김프)`, `z_t = encoder(K_t)`.
첫 단계 `y_t = a + b'z_t + r1_t`, 두 번째 `r1_t = c + d*g_t + e_t`.
인코더에는 **USDT y, g, 미래 값, BTC 하방 지표, 롱/숏 지표를 넣지 않는다**. 표준화와 인코더는 매월 이전 자료로만 적합한다. 글로벌 상대가격 g의 순차 OLS 조정은 유지한다. 인코더 학습 목표는 참조 코인 5종의 재구성이다. USDT는 이후 회귀와 과거 검증에만 쓰인다. g는 이전과 같은 절대 USDCUSDT 괴리이며 직접 USDT/USD 디페깅으로 이름을 바꾸지 않는다.

1. 기존 EQ5 순차 OLS, PCA1 순차 OLS를 그대로 재현한다.
2. PCA2와 과거 검증으로 차원 1/2를 고르는 PCA도 둔다. 추가 요인 때문에 생기는 개선을 비선형성으로 오해하지 않는다.
3. AE는 `5→8→k→8→5`, k=1/2, 숨은 활성화 ReLU/tanh, 출력 선형, L2 alpha=1/100. 8개 설정. L-BFGS max_iter=1500, max_fun=30000, tol=1e-6. 무작위 early-stopping 검증은 사용하지 않는다. seed=20260925/26/27의 3개 인코더를 각각 적합하고 각각 USDT에 OLS를 적합한 뒤 **예측을 평균**한다. 서로 회전할 수 있는 잠재좌표를 평균하거나 이어붙이지 않는다. 반복 한도·잠재 차원 붕괴·경고를 저장한다.
4. 조건부 민감도: PCA1 z와 `c=log(1+참조 김프의 단면 표준편차[bp])`를 각각 훈련 자료로 표준화한다. 대조군은 `a+z*(b0+b1*c)`. 신경망은 `a+z*(b0+b1*c+v'tanh(u*c+d))`. 폭=4/8 × 비선형 부분 L2 penalty=.001/.1, 총 4개 설정. 선형 부분을 벌점 없이 포함한다. 표준화한 y의 평균제곱오차를 L-BFGS-B로 최적화하고 3개 seed 예측을 평균한다. 이 분산도가 경제적 상태라는 해석은 검토할 가설이지 식별된 구조가 아니다.

선형 대조 4개 + AE 8개 + 조건부 신경망 4개 = **16개 후보**. AE 차원·활성화별 4개 모형군과 조건부 NN 모형군 결과를 모두 남긴다.

ReLU 네트워크는 초기의 죽은 병목 뉴런을 줄이기 위해 v1 논문의 초기화 설명을 참고해 bias를 1로 시작한다. tanh는 sklearn 기본 초기화다. 초기화 방식은 실자료 평가 전에 고정하며 실패한 seed를 사후에 골라 버리지 않는다.

실행 전 합성 자료 검증에서 로컬 sklearn 1.3.2의 다변량 `squared_loss`가 출력 차원에 대해 평균을 내는 반면 `_backprop` 기울기는 합을 내는 불일치를 확인했다. 전역 라이브러리는 수정하지 않고 `ReconstructionMLP`의 손실을 `0.5*mean(sum((X-Xhat)^2, axis=1)) + alpha/(2*n)*sum(weights^2)`로 명시해 기울기와 일치시킨다. 실제 추정기 목적함수·기울기를 유한차분으로 검증한다. 선행 A3의 MLP는 단일 출력이므로 이 다변량 불일치와는 별개다. pandas 내부 메모리 배치가 바뀌어도 동일 자료·seed의 최적화 결과가 같도록 입력 배열 배치도 고정한다.

## 선택과 평가

2025년 7월~2026년 3월 9개 월별 과거 적합, 잔차 원점은 8월~3월. 각 월 설정은 직전 최대 3개월의 시간순 검증 USDT MSE로 선택한다. 5개 시각 가정을 유지한다. 주 평가는 기존과 동일한 2026년 1~3월(자료 종료일까지), 보조는 월별·8~3월 결과다. 이미 본 표본을 새로운 확증 표본이라 하지 않는다.

- 각 AE 활성화·차원별 alpha 선택, 조건부 NN 선택을 보고한다.
- 모든 AE에서 과거 USDT MSE로 고르는 절차와, 과거 참조 코인 **재구성 MSE만으로 고르는 절차**를 따로 보고한다. 지표의 목적 불일치를 숨기지 않는다.
- AE1은 PCA1, AE2는 PCA2, AE 전체 선택은 과거 선택 PCA, 조건부 NN은 동일 입력의 조건부 선형 민감도와 비교한다. EQ5 OLS 대비도 보고한다.
- 학습 외 USDT RMSE/MAE, 참조 코인 재구성 MSE, 잔차 상관·구간 평균, 월별 성능·seed 예측 분산을 저장한다. 점수가 낮다고 잔차가 '참된 USDT 고유 수요'로 식별되는 것은 아니다.
- 3일·7일 달력 블록 2,000회로 고정 예측의 짝지은 RMSE/MAE 차이 구간을 계산한다. 재학습·모형 선택·후보 탐색·다중 비교 전체를 반영하는 확증 구간은 아니다.

## 같은 후속 분석과 검증 범위

모든 최종 방법에 `three_way`의 동일 원점·통제·q10/q50/q90·정확한 1/6/12시간 분석, 기본/거시 통제, 공통 원점 분석, 전후반·스트레스 일자 민감도를 적용한다. e(t)와 e(t+h)는 반드시 **원점월의 같은 분해 함수**로 계산한다. 이번 후속 계수는 점추정 비교이며 새 AE의 재적합 신뢰구간 또는 새로운 인과 입증으로 표시하지 않는다. 기존 연구와 같은 부호·유의성이 되는지는 설정 선택에 쓰지 않는다.

입력 해시와 기존 원고 보존, 미래값 변경 시 훈련 불변, USDT 변경 시 인코더 불변, 조건부 신경망 도함수의 수치검증, 선형 대조 재현, 저장 가중치의 독립 예측 재구성, 과거 검증 선택의 독립 재구성을 확인한다. 결과가 나온 뒤 유리한 설정을 추가하거나 평가 기간을 바꾸지 않는다.
