# A4 수치 안정성 후속: 인코더 고정, 요인 회귀 정규화

초기 A4 평가와 가중치 재생 검산 후 일부 2요인 AE가 거의 같은 요인을 생성해 OLS 계수가 폭증하는 것을 확인했다. 예를 들어 NY/NY 2025-07 f07의 학습 이후 예측 중 약 -2.85e10 bp가 있었고, 참조 재구성만으로 고른 절차에도 초기 월에 극단값이 있었다. 이는 자료의 경제적 가격이 아니며 잠재좌표→USDT 회귀의 불안정이다. 원 결과를 `results/`에 그대로 남기고 주 해석은 `stabilized/`의 아래 안정화 비교를 사용한다.

신경망을 다시 학습하거나 seed/후보를 추가·삭제하지 않는다. 원 720개 후보×월×시각 가정의 가중치를 불러온다. 모든 AE의 잠재좌표를 기존 훈련 기준으로 표준화한 후, USDT 1단계 회귀를 `sum((y-a-z*b)^2)+1*sum(b^2)`의 **Ridge alpha=1, 절편 무벌점**으로 재적합한다. 동일 차원의 PCA1/PCA2도 훈련 자료로 요인을 표준화하고 같은 Ridge를 쓴다. g 조정은 이 1단계 잔차에 대해 원래 순차 OLS로 다시 적합한다. EQ5 OLS와 조건부 민감도 모형은 그대로 둔다.

alpha=1을 고정하며 평가 성능을 보고 여러 alpha 중 고르지 않는다. 모든 월의 과거 검증 손실을 안정화된 예측으로 다시 계산하고 원래의 선택 규칙을 적용한다. 같은 원점·정확한 시계·동일 후속 분석·고정 예측 블록 구간을 다시 계산한다. 인코더의 손실/경고는 원 실행 기록을 유지한다. 결과를 본 후 실시한 수치 안정성 점검이므로 초기 사전 고정 실험이나 새 확증 검정으로 부르지 않는다.

초기 검산 코드가 모든 크기의 예측에 절대 허용오차 1e-7 bp만 사용해 거대한 실패 후보의 CSV 왕복 반올림 차이에도 중단했다. 원 검산 코드를 보존하고 `verify_replay.py`에서 절대 1e-7 bp + 상대 1e-12의 재생 기준을 사용했다. 초기 최대 차이는 3.82e-6 bp이며 계산 실패 후보를 지우거나 적합 결과를 바꾼 것은 아니다. 안정화 실행도 저장 가중치를 별도 구현으로 다시 계산해 검증한다.
