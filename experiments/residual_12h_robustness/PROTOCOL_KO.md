2026-09-26. 기준 커밋 `5e49ca7`. 이전 12시간 EQ 결과(4 seed 평균 선형 대비14.89%, 문턱형 대비10.29%)와 3월 보정 후 악화를 **이미 확인한 뒤** 계획한 후속이다. 기존1시간 주 결과·교수님께 전달한 당시10.6%·최근12시간 결과는 서로 다른 설계의 수치다. 이 작업도 같은 과거 기간을 사용하는 탐색적 검증이며 독립 확인이나 게재 가능성의 확정이 아니다. 추가 수집은 하지 않는다.

## 잔차 정의별 비교

- 기존 순차 회귀·가용 정보 규칙·가격 단위(bp)를 유지한다. EQ, 고정 유통량을 이용한 시총가중 대용 CAP, 과거 자료에서만 적합한 PCA 제1요인을 각각 사용한다. PCA 잔차도 공통요인에 회귀한 잔차다. 잔차 정의가 다른 절대 손실을 직접 비교해 더 진짜인 잔차를 고르지 않는다.
- actual12h/q10, available_macro, Aug2025부터 후보 OOS 이력, Sep부터 내부 점수, Dec2025~Mar19 2026 평가. 사전 자료 점검에서 세 정의 모두139/137/128/105개로 동일한509개 시점이다. 모든 모델/입력/정의의 시점과 정의 내부 정답 일치를 확인한다.
- original 및 own_scale(과거72h 실제1h 잔차 변화 RMS) 두 입력 버전을 모두 유지한다. R/B/F 및 선형/QRF/분위수 부스팅/문턱형을 비교한다. 기존60개 설정, all/90일 창, level/change 표현, 난수20260925 선택을 그대로 사용한다.
- 후보별 자기 과거60개 오차(최소30/최대90일)의 q10으로 보정한다. target_time<origin만 사용한다. 과거3개 내부 월의 보정 후 손실로 매월 선택한다. 내부 월 경계를 넘는 목표를 제거한다. 계산 효율을 위해 같은 내부 점수는 한 번만 계산하되 기존 NumPy 평균/동점 시 작은 ID 규칙을 그대로 재현한다.
- EQ 후보/첫 seed 결과와 기존 F의 추가 seed 이력은 해시와 일치를 검증해 재사용한다. CAP/PCA 첫 seed에서는60개 후보 전체를 재학습한다. 선택된 ML 설정에 대해 나머지3개 seed(20260926~28)의 자체 OOS 오차 이력도 생성한다. 첫 seed의 과거 선택을 고정하며 추가 seed로 후보를 다시 선택하지 않는다. EQ R/B도 이 규칙으로 추가 seed를 실행한다.
- 네 seed의 **시점별 손실 평균**으로 ML 선택 절차를 평가한다. 선형/문턱형은 결정적이다. QRF/부스팅 계열별 부표는 첫 seed만이며, 전체 후보 격자가 네 seed에서 다시 선택된 것으로 표현하지 않는다.
- 기존6개 비교(ML R/선형 R, ML F/선형 F, ML B/R, ML F/B, ML F/R, ML F/문턱형 F)를 세 정의×두 버전에서 전부 보고한다(36개). 보정 후36개에 대한5일 월별 달력 블록 bootstrap1999회 및 Holm p를 보고한다. 1/10일 블록·원예측·월별·seed별 결과도 공개한다. 개별 백분위95% 구간과 중심화 양측 p는 정확한 역관계가 아니다. 적합 예측에 조건부이며 모든 과거 탐색을 교정하지 않는다.
- 세 정의에서 동일 입력 ML의 우위가 유지되는지와 포지셔닝 추가 효과를 별도로 판단한다. 불리한 정의/월/버전을 삭제하지 않는다. 원래1시간 주 분석이나 이전81개 검정을 바꾸지 않는다.

## 3월 악화 진단: 모델을 결과에 맞춰 재조정하지 않음

1. **동일 후보의 보정 효과를 산술 분해한다.** G_raw=L_ref_raw−L_ML_raw, G_cal=L_ref_cal−L_ML_cal로 정의한다. G_cal−G_raw=(L_ref_cal−L_ref_raw)−(L_ML_cal−L_ML_raw)의 항등식으로 상대적 악화가 ML의 절대 악화인지, 비교모형의 더 큰 보정 이득인지 구분한다. 보정 후 선택한 같은 후보의 raw/cal을 비교하며 raw 결과로 후보를 재선택하지 않는다.
2. 예측 하회율(기준10%), 보정 크기/부호, 원예측 오차의 월별 분위수, 후보의 보정 오차60개가 포함하는 달/일 수/최신 및 최장 지연을 보고한다. 후보가 월마다 바뀌면 그 후보의 고유 과거 이력을 사용한다. 과거에 **선택된 전략**의 이력으로 섞지 않는다.
3. 각 월 학습 표본의1/50/99% 경계와 평가 분포/범위 밖 비율로 상태 이동을 점검한다. e_now,e_change1,e_rms72,btc_vol24,account_log,funding_bp,oi_ret1,oi_change24,local_volume_surprise,fx_ret1를 미리 정한다. 설명적 분포 비교이며 원인 식별/SHAP 인과 주장과 다르다.
4. 3월은19일까지의 부분 월이다. 각 월에서도20일00:00UTC 이전에 목표가 도착한 관측으로 제한한 같은 길이의 달력 구간 진단을 함께 보고한다. 같은 관측 수나 같은 시장 상태가 보장되는 것은 아니다.
5. 3월 날짜별 손실차이와 모든 날짜를 각각 하나씩 뺐을 때의 변화 범위를 보여준다. 손실로 사후 순위를 매긴 날은 기술적 진단일 뿐이며, 특정 날짜를 뺀 값을 새 주 성과로 삼지 않는다.

3월 raw와cal의 비교는 개별 모델의 보정 이득을 구분하는 분석이다. 분포 변화와 손실이 동반돼도 경제적 인과를 단정하지 않는다. 보정창/알고리즘을 바꾸는 성능 최적화는 이 설계에 포함하지 않는다. 필요성이 드러나면 결과 이후 별도 개발로 기록해야 한다.
