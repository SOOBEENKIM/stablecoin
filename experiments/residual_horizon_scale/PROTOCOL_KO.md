# 결과 이후의 진단과 제한된 보완 실험

이 실험은 factorial 결과를 본 뒤 설계한 **탐색적 개발**이다. 이전 주 분석의 판정을 바꾸거나 새 독립 검증이라고 주장하지 않는다. 실패는 ML 일반의 불가능성을 뜻하지 않는다. 반대로 아래 가설도 실제 자료에서 확인되기 전에는 원인으로 단정하지 않는다.

## 진단 가설과 반증 조건

1. 최근 factorial은 1시간 뒤 분위수만 다뤘다. 원고의 지연 반응 질문은 6·12시간을 포함한다. 정확한 시계 시간의 6·12시간에서도 입력 정보의 추가 효과가 없으면 지연 반응으로 예측 기여를 설명하지 않는다. 원고의 과거 관측행 이동을 시간으로 인정하지 않는다.
2. R의 잔차 정보는 현재 수준과 직전 1시간 변화 두 개뿐이고 B의 변동성은 BTC 것이다. 잔차 자체의 최근 변동 폭을 추가해도 손실·조건부 초과율이 개선되지 않으면 이 보완을 성공으로 부르지 않는다.
3. 전체 q10 초과율이 약 10%여도 특정 상태에서 틀릴 수 있다. 기존 예측을 현재 잔차, 직전 변화, 자체 변동 폭의 학습구간 3분위로 나눠 진단한다. 외부 결과로 구간을 고르지 않는다. 조건별 표본 수와 월별 결과를 함께 공개한다.

## 이번에 바꿀 두 축

- 잔차 정의 EQ / available_macro, 월별 과거 자료만으로 기존 순차 회귀 유지.
- 예측 목표: 실제 h=1,6,12시간 뒤 잔차의 조건부 q10. 미래 경로의 최저점·손실확률·인과효과와 구분한다.
- `original`: 기존 R/B/F 입력. `own_scale`: 각각에 `e_rms72` 하나 추가. 이는 (t−72h,t] 안에서 양 끝이 실제로 관측된 1시간 잔차 변화의 제곱평균제곱근이다. 최소 12개 변화가 필요하고 결측을 0으로 대체하지 않는다. 평균을 뺀 표준편차가 아니라 **최근 변화의 RMS**다. 예측 시점의 완료된 1시간 변화까지 사용한다. 잔차 회귀 계수는 월 시작에 고정한다.
- 두 입력 버전의 학습·평가 관측은 각 h에서 완전히 같다. 사전 자료 점검상 결측 추가가 없지만 있으면 중단한다. 시차마다 가용 관측이 다르므로 공통 시작점 239개의 보조 결과도 전부 보고한다. 이는 예측 당시 알 수 없는 미래 자료 가용성으로 제한한 사후 진단이며 배치 가능한 선별 규칙이 아니다.
- 기존 60개 설정(선형12/QRF12/부스팅12/문턱형24), 학습 창 all/90일, 수준/변화량 표현을 그대로 사용. h마다 별도 학습한다. 새 격자 탐색 없음.
- 이번 제한된 개발 실행은 기존 첫 seed=20260925. 난수 강건성이나 잔차 정의 간 강건성이 새 실험에서 확인됐다고 주장하지 않는다.
- Aug 2025부터 후보별 OOS 오차 이력, Sep부터 내부 점수, Dec 2025–Mar 19 2026 외부 평가. 각 후보별 과거 60개 오차(최소30,최대90일)의 q10으로 보정. **target_time < origin**인 오차만 사용. h별 오차를 섞지 않는다.
- 직전 3개월의 보정 후 pinball 손실로 계열 내 설정, QRF/부스팅 중 ML 선택. 내부 월 경계를 넘는 미래 라벨 제거. 모든 60개 후보와 시점을 유지하고 경고/결측/표본 부족 시 중단한다. h=1 original은 저장된 동일 후보 예측을 재사용하되 자료·과거 선택·보정 동일성 확인.

## 비교와 판정 범위

모든 h·두 입력 버전에서 기존 6개 비교(ML R/선형 R, ML F/선형 F, ML B/R, ML F/B, ML F/R, ML F/문턱형 F)를 보고한다. 추가로 각 h·R/B/F·5전략에서 own_scale/original 효과를 보고한다. 원래6×3×2=36, 추가3×3×5=45, **81개** 개발 비교를 공개하고 5일 블록 기준 Holm 보정도 81개 전체에 적용한다. 원/보정 예측, 월별 손실·초과율, 1/5/10일 블록 구간을 모두 보존한다. 95% 구간은 개별 백분위 구간, p는 중심화 절대차이 bootstrap이다. 두 방법은 같은 검정의 역이 아니다. 검정은 적합된 예측에 조건부이며 모든 과거 인간 탐색을 교정하지 않는다. 공통 시작점 비교는 5일 블록의 보조 기술 결과다.

추가 입력 효과가 선형에도 나타나면 ML만의 성과로 부르지 않는다. ML이 선형보다 좋아도 문턱형 대비·포지셔닝 추가 효과를 별도로 확인한다. 예측 개선은 경제적 원인/인과 매개의 증명이 아니다. 결과가 나쁘면 숨기거나 이 설계의 목표를 사후 교체하지 않고, 무엇이 반증됐는지 기록한다.

## 구현 검증과 기록

새 파일에서만 작업하고 이전 잠금·예측·결과는 수정하지 않는다. 시계 시간 조회, 결측 처리, 미래 입력 교란 불변성, h별 보정 라벨 시점, 독립 보정 산술, 과거 선택, 동일 입력/표본, 가격 분해 항등식, h=1 기존 예측/선택 일치를 검증한다. 실행 코드·설계·테스트·의존 파일을 SHA256으로 잠그고 커밋/원격 저장한 뒤 전체 적합한다. 예측 봉인 후 검증을 통과해야 성능표를 생성한다.

## 문헌상 아직 남아 있는 방법론

현재 QRF는 평균 제곱오차로 나무를 분할한 뒤 리프의 분포로 분위수를 구한다. 이는 알려진 QRF 방식이며 자체로 구현 오류가 아니다. [Cevid et al., JMLR 2022](https://jmlr.org/papers/v23/21-0585.html)는 평균이 비슷해도 분포/분산이 다른 경우를 다루기 위해 분포 차이를 이용한 분할을 제안한다. [GRF의 quantile_forest](https://grf-labs.github.io/grf/reference/quantile_forest.html)도 분위수용 분할을 제공한다. 따라서 ML 접근을 모두 소진했다고 말할 수 없다. 이번에는 두 설계 축의 원인을 분리하기 위해 새 forest 알고리즘까지 동시에 바꾸지 않는다. 해당 문헌은 이 자료의 개선을 보장하지 않는다.
