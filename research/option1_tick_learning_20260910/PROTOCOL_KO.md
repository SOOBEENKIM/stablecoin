# 1안: 호가 구조를 반영한 입력 증강 학습

2026-09-10. 본 학습·신규 성능을 계산하기 전에 고정한다. 같은 역사적 표본을 여러 번 관찰했으므로 탐색적 확장이다. 1안의 측정 결과는 보존하며, 미래 목표를 바꾸거나 3안의 공동 목표 학습을 실행하지 않는다.

## 연구 질문과 고정 목표

기준 코인의 실제 상대 호가 크기에 맞춘 학습 입력 증강이 미래 한국 USDT 상대가격 예측의 정확도를 유지하면서 입력 가격 변화에 대한 취약성을 줄이는가? 주 목표는 기존 mean5의 실제 6시간 뒤 값이다. 평균·중앙값 등 목표 자체의 측정 차이를 해소했다고 주장하지 않는다.

원시 UTC 시간봉 시작+1시간을 종가 관측 시각으로 사용하고 실제 24시간 이력을 만든다. 주 학습은 신규 주문 단위가 확정된 2025-08-02 이후 시간만 포함하는 이력에서 시작한다. 전환 시각과 구형 주문 영향을 피하는 범위 제한이며 기간 선택 최적화가 아니다. 2025-12월은 과거 오차 보정 준비, 2026년 1~3월은 평가다. 이전 모델 예측과 공통 origin에서 별도 비교하며 표본 축소도 보고한다.

## 입력과 시나리오

매 시간 입력: 다섯 개별 기준 괴리, 평균·중앙값·기준 간 표준편차, 다섯 해외 코인 시간 수익률, 다섯 국내/해외 코인 수량 거래량 log 비율, USDT 가격 범위·거래량 변화·종가 불변 여부, BTC 과거 24시간 변동성, 시간 sine/cosine·주말, 다섯 상대 호가 크기. 같은 입력을 모든 새 모델에 제공한다. 모델에 따라 호가 정보 자체가 누락되는 비교를 하지 않는다.

관측 입력의 기준 코인 한 종목을 선택해 국내 종가를 실제 가격대의 위/아래 한 호가로 이동한다. 미래 목표와 USDT 가격·해외 가격·거래량은 그대로 둔다. 이때 개별 괴리·평균·중앙값·분산·상대 호가 크기를 다시 계산한다. 원시 가격과 파생 특징의 일관성을 검증한다. 실제 가격이 잘못됐다는 가정이나 공격 확률은 아니다.

훈련 중 절반의 사례에 증강을 적용한다. 코인과 방향은 균등, 시간 패턴은 최신 1시간 또는 최신 6시간에 같은 코인의 같은 방향 이동을 적용하며 반반 선택한다. 각 시간 가격대의 호가를 사용한다.

일반 잡음 대조는 같은 donor 코인·방향·시간 패턴·가격 log 변화 크기를 다른 recipient 코인에 무작위 배치한다. 각 시점에서 코인 log 가격 변화 절댓값의 합이 호가 증강과 정확히 같다. 전체 표준화 특징 벡터의 L2 norm까지 같다는 주장은 아니다. 평균 괴리에 전달되는 변화 크기도 같다. recipient를 섞기 때문에 실제 코인별 격자 구조는 지켜지지 않는 대조다. 이를 ‘크기를 맞춘 배치 무작위화 증강’으로 부르며 Gaussian 잡음과 구분한다.

평가 입력은 원자료와 최신 1/6/24시간에 한 코인 ±1호가를 적용하는 각 10개 시나리오다. 1시간 시나리오가 주 강건성 평가, 6시간은 학습 범위 민감도, 24시간은 학습하지 않은 지속 패턴 평가다. 모든 모델이 같은 미래 관측 목표를 예측한다. 사후 미래 목표를 변경하는 기존 실험과 구분한다.

## 모델과 학습

TCN은 16채널, dilation 1·2·4, 각 두 causal convolution, kernel 3, dropout .1, 세 분위수 출력이다. 기존 TCN이며 신규 신경망 구조를 주장하지 않는다. 선형 신경층은 현재·최근 6시간 평균·최근 24시간 평균 특징에 세 선형 출력을 둔다. 둘 다 clean / tick / shuffled 세 방식으로 적합한다. 일반 empirical pinball loss에 증강을 넣는 방식으로, 정확한 minimax/DRO 최적화라고 부르지 않는다.

각 방식에 seeds 20260910·11·12를 모두 사용한다. 주 결과는 세 seed 예측 평균이며 seed별 결과도 공개한다. TCN AdamW lr .001, 선형층 lr .005, weight decay .001, batch 128, 최대 60 epochs, 직전 28일의 관측 가능한 validation 꼬리 손실로 patience 8을 적용한다. TCN·선형 각 구조 내에서는 초기값, 배치 순서, 증강 donor·방향·패턴을 seed별로 맞춘다.

각 달 최초 시점 이전에 target이 이미 관측된 행만 학습한다. 내부 validation 시작 전에 target이 관측된 행으로 epoch 선택 후, 같은 달 시작 전 전체 과거로 재적합한다. X·y 정규화는 해당 적합의 과거 행에서만 추정한다. 각 달마다 재적합하고 6시간 label purge를 검사한다. 이상치를 제거하거나 성능에 맞춰 손실·표본을 바꾸지 않는다.

새 선형 분위수회귀(정확한 L1 penalty alpha .01, HiGHS)와 LightGBM(num_leaves7,150trees,lr.03,min_leaf100,lambda10)을 같은 현재/6시간평균/24시간평균 특징과 과거 표본에 별도로 적합한다. 이는 선형 신경층의 최적화 부족을 AI 우위로 오인하지 않기 위한 강한 비교다. 기존 1안의 보정 선형·트리 예측도 공통 표본으로 비교한다.

## 보정과 평가

q10·q50·q90를 출력한다. 모든 모델의 분위수 출력은 예측 단계에서 정렬한다. 각 origin보다 엄격히 이전에 target이 관측된 최근 28일의 원래 입력 예측 오차로 q별 오차 보정을 적용한다(min120). 세 seed를 평균한 뒤 주 보정을 수행한다. 동일 origin의 모든 입력 시나리오에는 같은 과거 보정값을 적용한다. 평가 시나리오의 미래 오차로 다시 보정하지 않는다.

원래 입력에서 양 꼬리 평균 pinball loss, q10 loss, 80% 포함률과 폭을 보고한다. 주 스트레스 손실은 각 관측에서 원자료와 최신 1시간 10개 시나리오 중 양 꼬리 손실 최댓값을 구한 뒤 평균한다. 안정성은 q10/q90 예측이 원래 예측에서 바뀐 절댓값의 최대치를 관측마다 계산해 평균한다. 6/24시간은 보조로 모두 공개한다.

주 비교는 tick TCN 대 clean TCN, shuffled TCN, tick 선형층, 새 정확 선형 QR이다. 5일 달력 공통 블록 1,999회로 차이·비율의 구간을 계산한다. 네 주 스트레스 손실 차이에 Holm 보정한다. 평균 3-seed는 주 절차이며 시간 관측과 seed를 독립 표본처럼 부풀리지 않는다.

실질적인 성공 기준: 상대 모형 대비 clean 꼬리 손실 비율의 단측 95% 상한 <=1.02, 주 스트레스 손실 최소 10% 감소 및 보정 후 차이 유의, 예측 민감도 최소 10% 감소, 포함률이 .80에서 더 멀어지는 정도 <=.01, 평균 폭 증가 <=5%. 최소 clean·shuffled TCN 대비 모두 충족해야 호가 배치의 추가 가치를 주장한다. 정확 선형 QR/기존 강한 선형보다 못하면 강한 AI 성능 개선을 주장하지 않는다. seed와 월별 방향도 공개한다.

구간을 넓히거나 상수에 가까운 예측을 만들어 안정성만 개선하는 경우는 성공으로 분류하지 않는다. 일부 지표만 좋아지면 trade-off로 보고한다. 성능이 나쁘면 기존 측정 논문 결론을 유지하며 이 AI 확장은 실패로 기록한다.
