# 시계열 신경망 추가 비교

기존 LightGBM 발생 경보 결과를 본 뒤, 다른 모형의 적합성에 관한 요청에 따라 추가한다. 첫 파일럿의 결과와 프로토콜을 보존한다. 이번 추가가 독립적인 검증이 되지는 않는다. LightGBM 실패를 모든 AI의 실패로 일반화하지 않는다.

## 질문과 고정 범위

같은 BTC·ETH 공통 하단 발생 목표에서, 지난 24시간의 순서를 직접 학습하는 모형이 현재 시점의 요약 변수 모형보다 도움이 되는가? 임계값, 실제 6시간 미래 라벨, 현재 C=0 조건, 월별 확장 학습과 평가 월은 기존 발생 경보 파일럿과 동일하다.

입력은 기존 reference 33변수의 t-23,...,t 총 24개 실제 시간 관측이다. 입력 창에는 현재 C=1인 과거 시점도 포함해야 하며, 필터한 행의 앞 24개를 쓰지 않는다. 입력 결측이 있는 창은 제외하고 같은 origin에서 모든 모형을 평가한다. 환율 자료나 새 외생변수는 넣지 않는다.

- GRU: 한 층, hidden=16, 마지막 hidden에서 이진 logit.
- TCN: 인과적 1차원 합성곱 잔차 블록 3개, dilation=1/2/4, 각 블록 kernel=3인 합성곱 2개, channels=16, dropout=.1, 마지막 시점에서 이진 logit. 29시간 수용범위이나 입력은 24시간이다.
- MLP-current: 마지막 시점 33변수, hidden=16, ReLU, dropout=.1. 신경망 자체와 시계열 입력 효과를 구분하는 비교군.
- 같은 24시간 전체를 펼친 L2 로지스틱(C=.1)과 현재 시점 로지스틱(C=.1), 같은 현재 시점 LightGBM을 동일 학습 origin으로 다시 적합. 순서 정보가 선형 지연항만으로 충분한지 확인한다.
- 최근 28일 및 조건부 빈도 예측은 첫 파일럿과 같은 origin의 값을 쓴다.

신경망은 AdamW lr=.001, weight_decay=.001, batch=128, gradient norm clip=1, 최대 50 epochs. 각 월 학습 자료의 마지막 28일을 내부 검증으로 분리한다. 내부 학습의 target_time은 내부 검증 시작보다 엄격히 과거다. 내부 검증 log-loss로 patience=7 조기 종료하고 선택 epoch 수만큼 해당 월 전체 과거 학습 자료에서 초기화하여 재학습한다. 입력 표준화는 각 적합의 학습 자료만 이용한다. seed=20260909/10/11 세 개를 모두 수행하고 평균 확률을 주 결과로 사용하며 개별 seed도 공개한다. 좋은 seed를 고르지 않는다. 무작위 minibatch 순서는 과거 학습 집합 안에서만 사용하고 시간 분할에는 사용하지 않는다.

주 비교는 GRU 평균 및 TCN 평균의 Brier 대 현재 시점 LightGBM/펼친 시계열 로지스틱/최근28일이다. 여섯 비교의 Holm 보정과 5일 달력 블록 1999회. 3% 개선·95% 개선 구간 양수·Holm p<.05·2/3개월 개선을 각 모형의 세 기준에 모두 요구한다. 원시 확률이 주 평가이며, 기존 월별 확률 보정은 보조로만 병기한다. 첫 파일럿에서 보정 악화를 이미 관측했으므로 이 선택을 명시한다. MLP와 개별 seed는 진단이다.

좋은 결과가 나와도 순서 효과는 추가로 시간 순서 제거 및 입력군 제거에서 확인해야 하고, 사건 단위 경보 효용 검증은 별도 필요하다. 실패하더라도 Transformer·LSTM·모든 AI가 불가능하다고 결론 내리지 않는다. 해당 고정 사양에서의 증거 범위만 보고한다.
