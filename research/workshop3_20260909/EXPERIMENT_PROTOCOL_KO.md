# 워크숍 3안의 제한된 실험 사양

이 문서는 3안의 목표 구성·표본 진단 뒤, 새 모형의 성능을 보기 전에 작성한 실험 사양이다. 1·2안에서 이미 관찰한 시장 기간을 사용하므로 독립 검증이나 사전등록이 아니다. 현재 상태는 설계·자료 준비 완료이며 신경망 적합 미실행이다.

## 고정 관측 문제

가격 기준은 mean5, median5, BTC 세 개로 고정한다. 실제 6시간 뒤 괴리의 10%·90% 분위수를 모든 유효 origin에서 예측한다. 현재 하단 여부로 origin을 거르지 않고, 미래 6시간 내 발생 여부를 예측했던 2안과 구분한다. 세 출력은 세 정의의 서로 다른 관측 목표이며, 일치 벌점을 주지 않는다.

입력은 design_data.npz의 현물 27특징×24시간이다. 초기 학습 타깃은 2025년 11월 1일 이전에 결과가 관측된 것만 사용한다. 가격 기준별 IQR은 11월 이전 가격으로 계산한 reference_scales.csv의 값으로 동결한다. 이는 비교 단위를 맞추는 상수이며 이후 가장 유리한 정규화로 교체하지 않는다.

실제 가격 단위 bp와 정규화 점수를 모두 공개한다. DOGE·USDT 1원 민감도 두 특징은 역사적 호가 단위가 아닌 산술적 시나리오다. 기준별 실제 호가의 인과효과나 비동시 체결 보정이라고 표현하지 않는다.

## 핵심 학습 구조

각 기준 j의 타깃은 (b_j,t+6−b_j,t)/s_j로 표현한다. s_j는 동결 IQR이며 예측값은 마지막에 현재 b_j,t와 s_j를 이용해 bp로 되돌린다. 모든 학습 기준선에도 같은 입력·타깃 표현을 적용한다.

TCN은 27개 입력 채널, 폭 16, 커널 3, dilation 1·2·4인 세 residual block, block마다 두 causal convolution, dropout 0.1을 사용한다. 마지막 시점의 공유 표현에 출력부를 붙인다. 각 기준의 두 출력은 center−softplus(width), center+softplus(width)로 구성해 순서를 보장한다. center를 조건부 중앙값이라고 해석하지 않는다.

기준 j의 손실 L_j는 전체 학습 표본에서 10%·90% pinball loss의 평균이다. 이미 s_j로 나눈 타깃이므로 기준별 단위를 정규화한 손실이다.

- 평균 학습: (L_mean5+L_median5+L_BTC)/3.
- 최악 과제 학습: τ log Σ_j exp(L_j/τ), τ=0.1 고정.

후자는 최대 손실의 매끄러운 근사다. 최대 손실과의 차이는 0 이상 τ log(3) 이하이며, 정확한 max 최적화라고 부르지 않는다. 손실이 큰 기준에 더 큰 gradient 가중치를 주되, 해당 기준의 관측값이나 정의를 변경하지 않는다.

전체 학습 표본의 과제별 평균 손실에 위 함수를 적용한다. 각 표본 또는 작은 minibatch의 최대를 낸 뒤 평균하는 다른 목적함수와 혼동하지 않는다. 자료 규모가 작으므로 full-batch 또는 수학적으로 동등한 gradient 계산을 사용한다.

공유 구조가 없는 기준별 독립 선형 모형에서는 각 과제를 따로 최적화하는 것으로 최악 학습손실도 최소화할 수 있다. 따라서 minimax라는 이름만으로 선형을 넘는 이점이 생기지 않는다. 공유 신경망의 통계적 학습 효과와 일반화가 실제로 개선되는지를 비교한다.

## 제한된 학습 예산과 시계열 분리

2025년 11월부터 2026년 3월까지 월별 확장 학습이다. 월 시작보다 target_time이 엄격히 과거인 라벨만 사용한다. 시간순으로 앞뒤 데이터를 합친 무작위 교차검증은 하지 않는다.

각 월의 과거 학습 구간에서 마지막 28일을 내부 검증 구간으로 둔다. 내부 적합 라벨은 그 구간 시작 전에 이미 관측된 것만 사용한다. 최대 150 epoch, 내부 검증 목적함수 15 epoch 미개선 시 종료, AdamW 학습률 0.001·weight decay 0.001·gradient clip 1을 고정한다. 선택한 epoch 수로 과거 전체를 처음부터 다시 적합한다. 입력 표준화도 해당 적합 구간에서만 수행한다.

seed는 20260909·20260910·20260911 세 개다. 주 예측은 세 seed 분위수의 산술 평균이며, 모든 seed를 공개한다. 좋은 seed를 선택하지 않는다. 두 TCN×세 seed×다섯 월, 30개 최종 월별 적합이 1단계 신경망 범위이며 내부 epoch 선택 적합은 별도로 기록한다.

평가 시작일은 2026년 1월 1일로 고정하되 유효 입력은 1월 2일 21시부터 있다. 평가 1,814개·77일을 공통 표본으로 사용한다. 현재 배열에서 구간 경계 때문에 초기 학습·개발 진단에 포함되지 않은 7개 origin은 누락 원인과 함께 보존한다.

## 강한 비교 기준

동일한 새 입력·표본·타깃으로 다시 적합한다. 과거 1·2안의 서로 다른 표본 점수를 가져와 새 모델 점수와 직접 대조하지 않는다.

1. 기준별 독립 규제 선형 분위수 회귀: 현재 27특징, 과거 적합 구간 표준화, L1 alpha=0.01, 두 분위수.
2. 기준별 최근 28일 관측 수준의 경험 분위수: origin 시점까지 관측된 가격만 이용.
3. 기준별 최근 28일의 관측 완료된 6시간 변화 분위수에 현재 값을 더한 예측.
4. 같은 구조의 평균 손실 TCN.

현재 특징 LightGBM도 보조 비교로 고정한다. 7 leaves, 150 trees, learning rate 0.03, min leaf 100, L2=10, seed 20260909를 사용한다. 강한 선형 또는 경험 분포를 무시하고 LightGBM 하나를 이기는 것만으로 채택하지 않는다.

모든 예측에 대해 raw와 같은 최근 오차 보정을 별도 보고한다. 보정은 이전에 발행됐고 target_time<현재 origin인 예측의 최근 28일 오차만 사용하며, 최소 120개가 필요하다. 각 기준·분위수별 오차 분위수를 더하고 순서를 정렬한다. 보정 이력 부족 시 raw를 사용하고 건수를 공개한다. 보정 자체의 신규성 또는 조건부 포함률 보장을 주장하지 않는다.

주 검정은 raw에서 수행하고, 같은 보정을 거친 비교에서도 이점의 방향이 유지되는지를 채택 조건에 포함한다. raw 실패 뒤 cal을 새로운 주 검정으로 바꾸지 않는다.

## 주 지표와 해석

기준별 normalized tail loss는 q10·q90 pinball loss 평균을 동결 IQR로 나눈 값이다. 최악 기준 점수는 평가 구간의 기준별 평균 점수 세 개 중 최대다. **매 시점 가장 나쁜 기준을 선택해 평균한 점수는 다른 통계량**이므로 주 지표로 사용하지 않는다.

평균 점수, 세 개별 기준 점수, 실제 bp 손실, 중앙 80% 포함률과 평균 폭을 함께 공개한다. 두 pinball loss는 적절한 상수배를 제외하면 80% interval score와 동등하므로, 넓이 증가 없이 포함률만 주장하지 않는다.

주 비교는 최악 과제 TCN 대 위 1~4번 네 기준이다. 각 비교의 5일 UTC 달력 블록 bootstrap 1,999회에서 동일한 날의 모든 origin·모델·기준을 함께 재표집한다. 각 반복에서 기준별 손실 평균과 그 최댓값을 다시 계산한다. 관측 표본의 최악 기준을 모든 반복에 고정하면 안 된다.

차이의 95% percentile 구간과 중심화 근사 p, 네 비교의 Holm 보정을 공개한다. 짧은 비정상 시계열과 최대 통계량의 추론 한계를 명시한다. 단순한 모형 조건부 bootstrap이며 전체 연구 선택 불확실성까지 해결하는 절차는 아니다. 1일·10일 블록, 6시간 비중첩 origin 여섯 위상, 월별 방향은 보조 분석이다.

채택 조건은 다음과 같이 고정한다. 숫자는 연구 운영상 기준이며 문헌에서 보장된 통과 규칙이 아니다.

- 네 기준 모두에 대해 최악 기준 손실이 3% 이상 낮고, 쌍별 감소량의 주 구간 하한이 0 초과, Holm p<0.05.
- 평균 손실은 각 비교 대상보다 1%를 넘게 나빠지지 않고, 어느 개별 기준도 2%를 넘게 나빠지지 않음.
- 각 비교에서 세 평가 월 중 적어도 두 달 개선 방향.
- 같은 오차 보정을 적용한 뒤에도 최악 기준 개선 방향 유지.

최악 기준만 좋아지고 나머지를 크게 희생하면 목적을 달성했다고 하지 않는다. 실패 시 다른 τ·시계·가격 기준·seed를 검색해 주 결과를 교체하지 않는다.

## 2단계: 채택 조건 통과 후의 기여 검증

1단계에서 개선이 있으면 같은 최악 목적을 가진 현재 특징 MLP(27→16 ReLU→6 출력, dropout 0.1)를 비교해 24시간 시퀀스의 추가 가치를 확인한다. 세 기준별 독립 TCN도 비교해 공동 표현의 효과를 확인한다. 계산량 차이와 파라미터 수를 함께 기록한다. 이 비교가 없으면 긴 이력이나 공동 학습이 필요했다는 주장을 하지 않는다.

기준별 정보 제거에서는 단순한 동일 시각 중복값 하나만 빼고 결론을 내리지 않는다. 예를 들어 개별 b_i에서 평균과 중앙값을 복원할 수 있으므로, 기준 구성 정보가 남는 모든 결정적 중복 열을 함께 처리한 입력군 제거를 설계·기록한다. 타깃은 항상 고정한다. 미래의 목표 자산을 입력에 새로 주는 oracle ablation은 사용하지 않는다.

해외 포지셔닝의 추가 가치는 별도 부차 실험이다. 기존 as-of 이용 시점 규칙을 재사용하고, 27개 입력 실험과 동일 origin에 한정한 기초·확장 모형을 함께 다시 적합한다. 실제 계정 방향 비율·미결제약정·funding을 인과적인 한국 수요나 레버리지 양으로 해석하지 않는다.

과거 데이터의 한 호가 perturbation은 산식 민감도 진단으로만 사용한다. 생성한 가격을 실제 반사실 또는 새로운 독립 데이터로 세지 않는다. 관측 최소호가 효과·실제 거래 비용·수익은 이 자료만으로 검증하지 않는다.

## 보고와 중단

가설, 데이터, objective, early stopping, 모든 seed, 입력군, 실패 결과를 함께 공개한다. 1단계 실패 시 3안의 AI 우위를 주장하는 원고는 만들지 않고, 1안과 3안 실패 원인을 함께 평가한다. 성공해도 최초성·인과성·일반화·수익성은 별도 입증 대상이다.
