# 1안 후속: 구조 변경과 어려운 호가 시나리오 학습

2026-09-10. 이전 TCN 결과를 본 뒤 설계한 후속 탐색 실험이다. 이 파일을 새 학습 전에 해시 고정한다. 새로운 독립 확증 표본으로 취급하지 않는다. 원자료·mean5 실제 6시간 뒤 정답·24시간 30개 특징·4개 월 적합·2026년 1~3월 1,814개 평가 시점·과거 28일 보정·31개 스트레스 시나리오는 이전 실험과 정확히 같다. 기존 결과는 재학습하거나 덮어쓰지 않는다. 3안은 보류 상태다.

## 질문

H1: 호가 증강의 효과가 TCN에 특유한가? GRU와 MLP에서 동일한 clean/tick/shuffled 학습을 수행한다.

H2: 무작위 증강의 평균 손실 대신 손실이 가장 큰 시나리오를 학습하면 스트레스 성능이 달라지는가? 같은 기존 TCN 구조에 hard_tick/hard_shuffled 학습을 추가한다. 이는 TCN 자체의 변경 없이 학습 목적·어려운 사례 선택을 변경하는 실험이다.

GRU는 30개 hidden state의 단방향 단층 GRU와 출력 dropout .1, 세 분위수 head(5,673 parameters). MLP는 동일한 전체 24×30 입력을 시간 순서대로 flatten해 8개 hidden unit, ReLU, dropout .1, 세 분위수 head(5,795 parameters). 기존 TCN은 5,923 parameters. 요약 입력으로 바꾸지 않아 모든 모형이 같은 정보에 접근한다. 수가 유사하더라도 모델 복잡도가 완전히 같다는 뜻은 아니다. 대형 Transformer나 반복적인 구조 탐색은 이번 범위에 넣지 않는다.

GRU/MLP의 clean/tick/shuffled는 기존 TCN과 동일한 3분위수 pinball 손실, half-sample 증강, donor/recipient/sign/span 난수 및 배치 순서를 사용한다. AdamW lr .001, weight decay .001, batch128, 최대60epoch, gradient clip1, 과거 clean tail validation 기준 patience8을 유지한다. 초기값은 기존과 같은 20260910/11/12이다. 구조 내 clean/tick/shuffled의 동일 초기값을 보장한다.

hard_tick/hard_shuffled는 각 학습 시점에 원래 입력+최신1시간 코인별±1호가 10개 후보를 평가 모드로 계산한다. 각 사례에서 3개 분위수 평균 pinball 손실이 가장 큰 후보를 고르고, 학습 모드에서 `0.5 L(clean) + 0.5 L(selected)`를 최소화한다. 후보 선택에는 해당 과거 학습 정답만 사용한다. 선택은 dropout 없이 하며 학습 모드 dropout .1은 유지한다. 이는 유한 후보의 어려운 사례 학습이고 연속적 공격의 전역 minimax 보장이나 새 알고리즘을 주장하지 않는다. 주 평가의 양 꼬리 손실과 훈련의 세 분위수 평균 손실이 다름도 공개한다.

hard_shuffled는 매 적합 seed+101에서 각 사례의 donor→recipient 무작위 순열을 고정한다. 각 donor/방향 후보의 log 가격 변화 크기는 hard_tick과 같고 코인별 배치가 다르다. 모든 후보를 본 뒤 선택한 사례의 변화 크기까지 동일하다는 뜻은 아니다. 두 방법의 후보 집합 수준 변화 크기를 맞춘다. 선택 목표, clean/selected 비중, 초기값, epoch 선택 규칙은 같다. 기존 tick은1/6시간 랜덤 증강이고 hard는1시간 후보를 선택하므로 전체 학습 절차의 비교다. 한 요인의 순수 인과효과로 해석하지 않는다.

추가 학습은 GRU/MLP×3방식×3seed×4월=72개와 TCN×2방식×3seed×4월=24개, 총96개 outer fit이다. 세 seed 예측을 평균한 후 보정하며 개별 seed/raw 결과도 모두 보고한다. 내부 과거 검증으로 epoch 선택 후 해당 월 이전 전체 자료로 재적합한다. 데이터 정규화와 시나리오 선택에 미래 평가 정답을 사용하지 않는다. 예측 시에는 모델이 미래 정답을 사용하지 않으며 31개 입력에 각각 단순 forward만 실행한다.

## 평가와 판단

새 8개 ensemble과 기존 모든 ensemble 및 선형 QR/LightGBM을 같은 시점에서 평가한다. 기존 모델 출력은 저장된 값으로 읽는다. clean 손실, 최신1/6/24시간 최대 손실, 예측 흔들림, 80% 포함률·폭, 예측 표준편차를 공개한다. 5일 달력 블록1,999회, 기존과 같은 난수·공통 가중치로 paired 추론한다.

이번의 주 비교 12개: 각 GRU/MLP tick 대 (자기 clean, 자기 shuffled, 기존 tick TCN, 선형 QR) 8개; hard_tick TCN 대 (기존 clean TCN, 기존 tick TCN, hard_shuffled TCN, 선형 QR) 4개. 스트레스 손실 차이에 Holm12를 적용한다. 기존4검정과 이번12검정에 대한 Holm16도 보조로 공개한다. 이전 연구 전체의 적응적 탐색을 이16개 보정으로 해결했다고 주장하지 않는다.

성공 기준은 이전과 같게 고정한다: clean 손실 비율 단측95%상한≤1.02, 1시간 스트레스 손실10%이상 감소 및 보정후유의, 흔들림10%이상 감소, 폭증가≤5%, .8에서 포함률 오차 증가≤.01. 부분 성과는 별도로 설명한다. 단순 모델 교체의 평균 성능 개선과 호가 학습 특유의 효과를 구분한다. 구조 비교는 같은 증강 방식끼리 먼저 해석한다. 시나리오 전체·월별·seed별 결과를 남기고 성공한 seed나 모델만 골라 결론을 만들지 않는다.

이번 실험에서 성공 기준을 못 넘더라도 다른 AI 전반의 불가능성으로 일반화하지 않는다. 반대로 성공하더라도 이미 관찰한 역사적 기간의 후속 탐색 결과이며 독립 재현이 필요하다. 미래 목표의 측정 불확실성은 이전 별도 실험의 발견으로 유지하고, 이번 모델 결과의 원인으로 입증됐다고 말하지 않는다.
