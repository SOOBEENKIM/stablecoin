# 1안 통제 요인 실험: 금융 후보 배치 × 평균/최대 손실 × TCN/GRU

2026-09-10. 이전 긍정적인 후속 결과를 본 뒤 설계한 탐색 실험이며, 새 학습 전에 이 프로토콜을 해시로 고정한다. 같은 역사적 평가 기간을 반복 사용했으므로 독립 확증으로 취급하지 않는다. 기존 연구·원자료·제출 원고를 보존하고 3안은 재개하지 않는다.

## 질문과 설계

금융시장 코인별 호가에 맞춘 후보 배치가 도움이 되는가, 평균 대신 어려운 후보를 학습하는 것이 도움이 되는가, 두 요인이 결합할 때 추가 효과가 있는가? TCN과 GRU에서 각각 2×2 요인 실험을 수행한다.

| 후보 배치 | 후보 손실 평균 | 후보 손실 최댓값 |
|---|---|---|
| 실제 코인별 호가(tick) | tick_mean | tick_max |
| 변화 크기를 맞춘 코인별 무작위 배치(shuffled) | shuffled_mean | shuffled_max |

데이터·미래 목표·특징·월별 표본·보정·평가 시나리오는 이전 검증 배열과 동일하다. 실제24시간×30특징으로 mean5의 실제6시간 뒤 값을 예측한다. 모델은 동일한 작은 TCN(5923개)과 GRU(5673개)다. 매시점 후보는 원래 입력과 최신1시간의 다섯 코인±1호가를 포함한11개다. 평균/최대 학습에 정확히 동일한 후보 배열을 사용한다. 후보의 개별 괴리·평균·중앙값·표준편차·상대 호가 특징을 재계산하고 미래 정답을 고정한다.

shuffled 후보는 seed+101의 난수로 각 학습 행에서 donor→recipient 무작위 순열을 만든다. 동일 donor/방향 후보의 log 가격 변화 크기는 tick과 같다. 금융 후보 배치만 다르며 전체 표준화 특징 L2까지 일치시키는 대조는 아니다. 최대 손실을 선택한 뒤의 변화 크기를 다시 강제로 같게 맞추지는 않는다. 후보집합을 맞추고 선택이 달라지는 효과까지 학습 절차의 결과로 본다.

## 학습을 정확히 맞추는 방법

후보 c의 L_c는 원래 순서의 q10/q50/q90 평균 pinball loss다. 두 손실은 다음과 같다.

- mean: `0.5 L_0 + 0.5 mean(L_0,...,L_10)`
- max: `0.5 L_0 + 0.5 max(L_0,...,L_10)`

0은 원래 입력이며 두 식 모두 같은11후보를 포함한다. 같은 minibatch에서 모든11후보를 한 번에 forward한다. 같은 학습 행의 모든 후보에 dropout 마스크를 공유한다. 후보 간 가격 차이와 무관한 dropout 우연성이 최대 후보 선택에 섞이지 않게 한다. 모델 내부에서 mean/max만 바꾸고 후보 수·clean 가중치·dropout rate .1·학습 단계·초기값·배치 순서·원시 표본을 일치시킨다. mean/max는 각각 평균/최대 후보 손실을 그대로 역전파한다. 후보 선택용 별도 eval forward를 쓰지 않는다.

이는 직전 hard 모델의 ‘eval 모드 후보 선택→train 모드 선택 사례 적합’과 다른 통제 구현이다. 직전 hard 결과의 수치 재현으로 오인하지 않고 별도 실험으로 명시한다. 유한 후보와 공유 dropout 하의 목적함수 비교이며, 연속적 공격의 전역 최적해나 새 알고리즘을 주장하지 않는다.

AdamW lr .001, weight decay .001, batch128, gradient clip1을 고정한다. 정규화는 각 월 이전 목표가 관측된 학습 자료만 사용한다. 초기값은20260910/11/12이다. 각 모델·월·seed의 네 조건은 **동일 epoch**를 사용한다. epoch는 이미 저장된 clean 모델의 과거28일 내부 검증 선택값에서 가져온다(TCN은 option1_tick_learning_20260910, GRU는 option1_model_followup_20260910). 해당 선택은 당시 미래 평가 자료를 사용하지 않았다. 현재 조건별로 다시 epoch를 고르면 학습량이 달라지므로 추가 최적화하지 않는다. 과거 자료에서 고정된 학습량의 효과를 묻는 실험이며 각 조건의 최적 튜닝 성능 비교는 아니다.

모델2×후보2×집계2×seed3×월4=96개 outer fit을 수행한다. 2025년12월은 과거 오차 보정 준비,2026년1~3월의 동일1,814개 시점을 평가한다. 세 seed를 평균한 후 최근28일 과거 관측 오차로 보정하고, 동일 origin의 모든 평가 입력에는 같은 보정값을 적용한다. seed별/raw/cal 결과를 모두 공개한다. 원래 입력+1/6/24시간 코인별±1호가의31개 평가 시나리오를 유지한다.

## 효과 분해와 검정

기본 결과 Y는 각 시점의 최신1시간 최악 입력에서 q10/q90 평균 pinball loss다. 낮을수록 좋다. 각 구조에서 아래7개 대비를 사전 지정한다.

1. 학습 집계 주효과: `0.5[(tick_max−tick_mean)+(shuffled_max−shuffled_mean)]`
2. 금융 배치 주효과: `0.5[(tick_max−shuffled_max)+(tick_mean−shuffled_mean)]`
3. 상호작용: `(tick_max−tick_mean)−(shuffled_max−shuffled_mean)`
4. 금융 후보에서 max−mean
5. 무작위 후보에서 max−mean
6. mean 학습에서 tick−shuffled
7. max 학습에서 tick−shuffled

두 구조의14개와 GRU−TCN 상호작용 차이1개, 각 구조 tick_max 대(동일 구조 기존 clean, 강한 선형QR)의4개 효용 비교를 합친19개 스트레스 손실 대비에 Holm19를 적용한다. 모델에서 이 차이가 난다는 통제 실험이며 시장 위험을 발생시키는 인과효과로 해석하지 않는다. 상호작용이 음수면 max의 이득이 무작위보다 금융 후보에서 더 크다는 방향이다. 주효과가 있어도 모든 조합이 개선된다는 뜻은 아니다. 두 구조에서 같은 방향이 유지되는지를 별도로 판단한다.

5일 달력 공통 블록1,999회,seed20260910을 사용한다. 앞선4+12비교와 합친 Holm35도 보조로 공개하되 역사 전체의 적응적 탐색을 해결한다고 주장하지 않는다. 원래 입력 손실·스트레스 추가 손실(Y−clean)·흔들림에 같은 효과 분해를 보조로 보고한다. 이 보조 지표의 구간은 개별 탐색 구간이며 주 검정을 대체하지 않는다. 월별·seed별 대비도 공개한다.

효용 비교4개에는 기존 성공 조건을 유지한다: clean 손실 비율 단측95%상한≤1.02, 주 스트레스 손실10%이상 감소 및 보정후 유의, 흔들림10%이상 감소, 폭 증가≤5%, .8에서 포함률 오차 증가≤.01. 요인 분해의 통계적 증거와 이 실질 성공 기준을 구분한다. raw/cal 방향이 달라지면 보정의 기여를 분리해 설명한다. 6/24시간 평가와 과거 hard TCN 결과는 보조 참고이며 주 조건을 바꾸지 않는다.

## 검증

원자료 기반 검증이 끝난 배열과 bitwise 일치, 미래 시각과 학습 시각 분리, 동일 후보의 mean/max 해시, tick/shuffled 후보 크기 일치, 동일 초기 상태·배치순서·dropout 무작위 경로·학습 단계, 중복 후보에 대한 동일 출력, 목적함수 및 gradient 수동 재계산, 모든 체크포인트의 예측 재현, 모든 보정값의 과거 조건과 통계 대비/상호작용을 확인한다. 학습 시 최대 후보 선택 비중을 코인/방향별로 저장하고 해석의 보조 자료로 쓴다.
